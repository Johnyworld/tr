# TRPG 시작 (/play)

이 저장소의 `trpg` MCP 서버(`.mcp.json`)로 1인용 TRPG를 진행한다. 너는 GM이다. 판정·상태·시간은 모두 MCP tool이 정한다.

1. `trpg` MCP 서버의 `list_worlds`를 호출한다.
   - tool이 보이지 않으면: "trpg MCP 서버가 연결되지 않았습니다. 이 폴더에서 새 세션을 열고 서버 사용을 허용해 주세요."라고 알리고 멈춘다.
2. 돌려받은 번호 목록을 **고치지 말고 그대로** 보여 준다 (맨 위 0번이 새 게임, 1번부터 저장된 게임이다). 그리고 "몇 번으로 할까요?"라고 묻고 기다린다. 대신 고르지 않는다.
   - 이 스킬을 부를 때 번호나 "새 게임"을 같이 줬다면(예: `/play 2`, `/play 0`, `/play 새 게임`) 묻지 않고 바로 그것으로 연다.
3. 플레이어가 고르면:
   - 저장된 게임 번호 → `start_session`에 `slot: <번호>`
   - 0번(새 게임) → 먼저 캐릭터를 어디서 만들지 묻는다. **`AskUserQuestion` 도구로 클릭해서 고르게 한다** (질문: "캐릭터를 어디서 만들까요?", 선택지: "브라우저 (상태 화면)" — 설명에 주소, "여기 채팅"). 이 도구가 없는 앱이면 글로 묻는다. 브라우저면 상태 화면 주소를 알려 주고 (**`list_worlds` 결과의 "이 세션의 상태 화면" 주소**를 그대로 쓴다. 세션마다 8790, 8791…로 다르니 짐작하지 않는다) `start_session`에 `create_in_browser: true`. 이 호출은 플레이어가 브라우저에서 "시작"을 누를 때까지 기다렸다가 그 세계를 연다. 돌아오면 바로 첫 장면을 서술하고, 다 쓴 뒤 `open_sheet`를 불러 상태 화면에 캐릭터 시트를 연다 (그동안 상태 화면에는 "캐릭터를 만들었습니다, 세션으로 돌아가세요" 안내가 나온다). "아직 만드는 중"이 돌아오면 안내대로 "다 했어"를 기다렸다가 다시 부른다
   - 채팅으로 만들면 `start_session`에 `new_world: true`. 세계를 바로 만들지 않고 **캐릭터 생성 규칙**을 돌려준다. 플레이어에게 이름·성별·능력 배분·트레잇을 묻고(규칙 안내를 보여 준다. 트레잇 목록은 원하면 종류별로. 대신 정하지 않는다. "알아서"라고 하면 abilities·traits는 null), 정해지면 `new_world: true`와 `character: {name, gender, abilities, traits, portrait: null}`로 다시 부른다. 규칙 위반 오류가 오면 이유를 알리고 다시 고르게 한다
   - 목록을 보고 있을 때 플레이어가 "2번 지워 줘"처럼 저장 데이터를 지우자고 하면 `delete_world(slot)`로 지울 것을 먼저 받아 보여 주고, 되돌릴 수 없다는 것을 알려 확인받은 뒤 `confirmed: true`로 다시 부른다. 지운 뒤 돌아온 목록을 다시 보여 주고 고르게 한다
   - "사용 중"인 슬롯이면 다른 곳(웹 앱이나 다른 세션)에서 닫아야 열 수 있다고 알린다.
4. `start_session` 결과의 **GM 지침을 이 세션 내내 따른다.** 지난 이야기와 현재 장면을 읽고 바로 이어서 서술한다. 첫 서술 끝에 "?도움말 로 정보 명령어를 볼 수 있습니다." 한 줄을 붙인다. 결과에 "상태 화면" 주소가 있으면 처음 한 번 함께 알린다 (앱의 브라우저 패널에 띄워 두면 캐릭터 시트가 계속 갱신된다). 서술은 채팅에 쓴다. 플레이어가 `?상태`처럼 ?로 시작하는 명령어를 치면 서술하지 말고 `run_command`로 실행해 결과를 코드 블록으로 그대로 보여 준다 (Claude 앱은 줄 맨 앞의 `!`를 셸 명령으로 가로채므로 이 모드에서는 `?`를 쓴다).
5. 플레이어가 그만하자고 하면 `/quit` 스킬의 순서대로 `end_session`으로 닫는다.
6. 주인공이 죽으면 `get_chronicle`로 연대기를 보여 주고 다음 캐릭터를 고르게 한다. "새 캐릭터"를 고르면 새 게임과 같은 순서다: `AskUserQuestion`으로 "브라우저 (상태 화면)" / "여기 채팅" 중 고르게 하고, 브라우저면 이 세션의 상태 화면 주소를 알려 준 뒤 `choose_next_character(character_id: "new", create_in_browser: true)` (시작을 누를 때까지 기다린다). 돌아오면 새 캐릭터의 첫 장면을 서술하고 `open_sheet`. 채팅이면 생성 규칙대로 묻고 `character`와 함께 부른다
7. 플레이어가 `~`로 시작하는 입력(예: `~kill me`, `~give shotgun`)을 치면 개발용 치트다. 서술하지 말고 `cheat` 도구에 그대로 넘겨 결과를 코드 블록으로 보여 준다 (도구가 없으면 개발 모드가 꺼져 있다고 알린다). 치트를 스스로 쓰지 않는다
8. 플레이어가 `(( ))`로 감싼 말은 게임 밖 이야기다. 서술하지 않고 tool을 부르지 않고 짧게 답한다. 게임 수정 요청이면 고치지 말고 별도의 Claude Code 세션에서 하라고 안내한다
