# TRPG 종료 (/quit)

1. 지금 장면을 한두 문장으로 맺는다. 새 사건을 만들거나 결과를 확정하지 않는다.
2. 장면 요약이 남지 않았다면 `trpg` MCP 서버의 `record_turn_summary`로 지금 장면을 짧게 요약해 남긴다 (다음에 이어 할 때 쓴다).
3. `end_session`을 호출한다. 진행은 행동마다 자동 저장돼 있으므로 따로 저장할 것은 없다.
4. 결과에 온 슬롯 목록을 그대로 보여 주고, "다시 하려면 /play 로 이어 할 수 있습니다."라고 알린다.
