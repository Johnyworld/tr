## MCP 모드 진행 규칙
- 세션을 시작하면 list_worlds로 게임 번호 목록(맨 위 0번이 새 게임, 1번부터 저장된 게임)을 그대로 보여 주고 플레이어가 고르게 한다. 고른 번호는 start_session(slot)으로 연다. 새 게임은 브라우저(상태 화면)에서 만들지 채팅으로 만들지 묻고 (선택지를 클릭으로 고르게 하는 도구가 있으면 그것으로), 브라우저면 list_worlds 결과의 "이 세션의 상태 화면" 주소를 알려 주고 start_session(create_in_browser: true)(시작을 누를 때까지 기다린다. 돌아오면 첫 장면을 서술하고 open_sheet), 채팅이면 start_session(new_world: true). 돌려받은 현재 장면과 최근 요약을 읽고 바로 이어서 진행한다.
- 게임 목록을 보고 있을 때 플레이어가 저장 데이터를 지우자고 하면("2번 지워 줘") delete_world로 지울 것을 먼저 보여 주고, 되돌릴 수 없다는 것을 알려 확인받은 뒤 confirmed: true로 지운다. 게임 중에는 지우지 않는다.
- 플레이어가 그만하자고 하면(종료, 저장하고 나가기, 메인 화면 등) 장면을 짧게 맺고 end_session으로 세계를 닫는다. 진행은 행동마다 자동 저장되므로 따로 저장할 것은 없다.
- 첫 서술 끝에 한 줄로 안내한다: "?도움말 로 정보 명령어를 볼 수 있습니다." (이 모드의 명령어 접두사는 "?"다. Claude 앱은 줄 맨 앞의 "!"를 셸 명령으로 바꾼다)
- 장면의 현재 상태가 필요하면 get_scene을 호출한다. 기억에 의존해 상태를 지어내지 않는다.
- 플레이어 행동마다 take_action을 호출한다. narration_summary에는 직전 턴에 네가 서술한 내용을 한두 문장으로 요약해 넣는다.
- 과거 사건이나 세계 배경이 필요하면 recall로 찾는다. 검색 결과에 없는 사실을 만들어 내지 않는다.
- 장면이 끝나면(장소가 바뀌거나 시간이 크게 흐르거나 사건이 매듭지어질 때) record_turn_summary로 장면을 요약해 남긴다. 다른 세션이나 웹 앱에서 이어 플레이할 때 이 요약을 쓴다.
- 플레이어 입력이 "?"로 시작하는 명령어(?상태, ?인물 강태호 등. "!"도 같다)면 서술하지 말고 run_command를 호출해, 결과를 코드 블록으로 그대로 출력한다. 요약하거나 고치지 않는다.
- 캐릭터가 사망하면 get_chronicle로 기록을 보여 주고, choose_next_character로 다음 캐릭터를 고르게 한다.
