## 5. 시간

### 5.1 평시: 행동 비용만큼 흐른다

- 행동 종류별 기본 소요 시간을 코드 테이블로 정의 (대화 10분, 수색 1~2시간, 보초 4시간 등)
- AI는 행동을 분류만 하고(`take_action`의 `activity`), 시간은 코드가 더한다
- 시간이 흐르면 NPC 일과, 시설 운영, 월드 클락이 함께 진행된다
- 게임 시간은 1일차 00:00부터 흐른 분(정수). 시작은 1일차 05:30
- 시간대: 새벽 04시 / 아침 06시 / 낮 10시 / 저녁 17시 / 밤 20시부터

| 활동 | 시간 (*임시*) | 방식 |
|---|---|---|
| 잠깐의 행동 `brief` | 5분 | 고정. GM이 시간을 쓰지 않은 턴에도 자동으로 흐른다 |
| 대화 `talk` | 10분 | 고정 |
| 식사 `eat`, 응급처치 `treat` | 30분 | 고정 |
| 수색 `search` | 1~2시간 | 15분 단위로 굴림 |
| 휴식 `rest` | 1시간 | 고정 |
| 작업 `work` | 2시간 | 고정 |
| 보초 `guard_duty` | 4시간 | 빨리감기 |
| 잠 `sleep` | 6시간 또는 지정한 시간대까지 | 빨리감기 |
| 기다림 `wait` | 1시간 또는 지정한 시간대까지 | 빨리감기 |

#### 5.1.1 이동 수단 (12-137)

- 아이템 `vehicle { speed, fuel, noise, road_risk }`. 이동(`move_to`)할 때 `take_action.ride`로 타면 이동 시간 × speed, fuel이 있으면 한 번에 하나를 쓰고(없으면 끌고 걷는다), 도착한 구역에 noise만큼 소음(감염체를 부른다, 7.5.2), 길 위의 일(12-53)이 생길 확률 × road_risk
- 사람 동행이 있으면 그 걸음에 맞춘다 (개는 따라 뛴다). 물을 건너거나 갇힌 곳에서 빠져나가는 길에는 탈 수 없다. 무게는 짐으로 치지 않는다 (끌고 다닌다)
- `post_apoc` (*임시*): 자전거(×0.55, 조용함, 길 위의 일 ×0.7: 구시가·쇼핑몰·휴게소 수색에서 드물게), 오토바이(×0.3, 기름병 하나, 소음 2, 길 위의 일 ×0.5: 휴게소 수색에서 드물게)
- 자동 플레이는 탈 것이 있으면 절반쯤 타고 간다
- 자동 플레이의 생존 행동 (12-139): 감염되면 혈청, 배고프면 먹기(상하는 것부터, 끓이지 않은 물은 나중에), 목마르면 물병, 담배, 추우면 불 피우기, 유해 묻기, 덫(놓고 하루 지나 거두기), 낚시·사냥. 새 기능의 밸런스를 자동 플레이로도 본다

### 5.2 빨리감기: 끼어들기 조건이 핵심

장거리 이동이나 전쟁 같은 큰 사건은 빨리감기로 넘긴다. 빨리감기는 "건너뛰기"가 아니라 **시뮬레이션을 빠르게 돌리다가 의미 있는 일이 생기면 멈추는 것**이다.

```ts
function fastForward(state, until: StopCondition) {
  while (!until(state)) {
    state = simulateTick(state);              // 1시간 또는 1일 단위
    const interrupt = checkInterrupts(state);
    if (interrupt) return { state, interrupt }; // 장면 모드로 복귀
  }
  return { state, interrupt: null };
}
```

- 1시간 틱으로 돌리고, 한 번에 최대 하루까지 감는다
- 상태는 바꾸지 않고 결과(멈춘 시각, 끼어든 사건)만 계산한 뒤 `time_advanced` 이벤트 하나로 기록한다

멈추는 조건:

- ~~이상 징후~~ (12-187에 뺐다): 시간대별 확률로 "낯선 냄새" 같은 낌새만 정하고 정체는 정하지 않던 임시 장치. 열세 시간 자면 열에 여섯이 이것으로 깼고, 끊긴 잠은 마음이 풀리지 않았다. 지금 깨우는 것은 실제로 무언가 있을 때뿐이다: 예정된 교전, 야영의 밤손님(12-148, 지켜보는 사람이 없으면 늦게 안다), 급한 이야기
- 조우 (감염체, 다른 무리, 부상자)
- 월드 클락 임계값 도달
- 조건이 맞는 스토리렛 발동
- 플레이어 상태 위기 (식량 바닥, 부상 악화)
- 플레이어가 지정한 조건 ("도착하면", "적이 보이면")

### 5.3 역할별 빨리감기 단위

| 역할 | 단위 | 멈추는 지점 |
|---|---|---|
| 간부 | 일~주 | 전황 보고, 배신, 협상 제안 |
| 분대장 | 일 | 작전 회의, 보급 위기 |
| 분대원 | 시간~일 | 교전 시작, 동료 부상, 탈영 제안 |
| 혼자·외부 무리 | 일 | 무리가 근처를 지나갈 때, 자원 고갈 |

빨리감기 결과 요약도 반드시 정보 필터(6장)를 거친다.
