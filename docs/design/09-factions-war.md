## 9. 세력과 전쟁

### 9.1 세력 스키마

```yaml
id: faction_c
population: 200
combatants: 80          # 전투 가능 인원 (보통 30~40%)
resources: { food: 0, water: 0, ammo: 0, medicine: 0, fuel: 0 }
territory: [node_ids]
morale: 0
cohesion: 0             # 내부 결속. 낮으면 이탈, 반란
leader: npc_id
disposition: { faction_a: -3, faction_d: 0 }
traits: [ruthless, opportunistic]
minor: false            # 외부 소규모 무리는 true
```

### 9.2 MVP의 전쟁: "보이지만 지휘하지 않는다"

- **세력 단위 전쟁은 코드가 추상 시뮬레이션**: 매일 습격, 소규모 교전, 영역 변화, 사상자, 자원 소모
- **플레이어는 개인 단위로 전쟁을 겪는다**: 정찰, 수색, 매복, 보초, 포로 이송, 협상 호위
- 적대 세력의 행동은 코드가 유효한 후보를 만들고 세력 성향 가중치로 선택 (결정적, 테스트 가능)
- 2차 이후: 대규모 전투, 외교(동맹, 휴전, 포로 교환). 분대 명령·지도부 회의·교역 방침은 12-31·12-33에서 넣었다 (9.11)
- 움직이는 부대 (2026-11-24 설계, `docs/war-parties-plan.md`): 하루 틱의 결과 대신 무리마다 몇 개의 부대가 실제로 걸어가 만나고 싸우고 도망친다. ① 부대 생성·이동은 12-314, ② 마주침은 12-315, ③-1 닿을 때 계산·장소 길·믿음은 12-316, ③-2 맞붙기·우두머리·지렛대는 12-317, ③-3 임무와 전쟁·길 위 이야기는 12-318. 다음은 플레이 테스트

### 9.3 자원

- 5종: **식량, 물, 탄약, 의약품, 연료**
- 인원수에 따라 매일 자동 소모. 가만히 있어도 상황이 나빠진다
- 분대원은 세력 창고가 아니라 **배급**을 받는다 (몰래 챙기는 것도 가능, 들키면 평판 하락)

### 9.4 구현 (9단계)

**콘텐츠** (수치는 모두 *임시*)

- `factions/*.yaml`: 이름, 공개 평판(`public`), 인구·전투원·자원 시작값, 사기·결속(-3~+3), 공격 성향(0~3), 다른 세력에 대한 태도(-3~+3, -2 이하면 적대), 세력 클락(`plans`)
- `locations/*.yaml`: 전선의 구역. `base`(거점)·`zone`, 시작 소유 세력, 인접 구역(한쪽에만 적어도 양쪽), 하루 산출. 장소 시스템이 생기면 장소의 상위 단위가 된다
  - 초안 9곳: A 거점, 동쪽 초소, 고가도로 너머 물류창고(C), C 거점, 강변 공장 지대(빈 땅), 구시가(빈 땅), B 거점, D의 진료소, E의 장터
  - 거점 산출은 텃밭·우물·채집·교역을 뭉뚱그린 값이다. 무리마다 소모보다 조금 모자라게 둬서 바깥 구역을 두고 다투게 한다
- `scenario.yaml`의 `war`: 1인당 하루 소모량, 생존 자원(식량·물), 교전당 탄약, 사상자당 의약품, 공격 확률, 배급 수준·사기·창고 사정을 부르는 말, 전황 소식 틀(조사 처리 포함)
- 자원 단위는 "사람-일" (식량 1 = 한 사람 하루치)

**하루 틱** (`core/sim/war.ts`, 결정적)

1. 생산: 소유 구역의 산출
2. 소모: 인원수만큼. 생존 자원이 모자라면 사기 -1, 인구 1% 사망, 사기가 -2 이하면 결속 -1
3. 세력 클락: 하루 한 칸. 다 차면 목표 구역을 총공격(병력 50%)하고 다시 시작한다
4. 교전: 공격 성향 × 확률로 하루 한 번. 내 구역과 맞닿은 적대 세력 구역에 습격(자원 약탈)·교전(사상자)·공격(구역 점령), 또는 빈 구역 차지. 전투력 = 내보낸 병력 × 사기 보정 × 탄약 보정(모자라면 0.6), 거점 방어 1.5배. 진 쪽 사상자는 내보낸 병력의 최대 20%, 이긴 쪽은 0~1명. 거점은 빼앗기지 않는다 (MVP)
5. 결속과 회복: 사기·결속이 모두 -2 이하면 이탈자. 굶지 않으면 사기가 시작값 쪽으로 돌아오고, 처음 비율까지 전투원을 다시 키우고, 식량이 넉넉하면 가끔 피란민이 합류한다 (끝없는 세계에서 세력이 사라지지 않게)

- 결과는 `war_day_simulated` 이벤트 하나(세력·구역·클락의 새 값과 교전 목록)로 남긴다. 시간이 흐른 뒤 날이 바뀌었으면 지난 날만큼(최대 7일) 돈다
- 세계를 열 때도 같은 처리를 한 번 맞춘다. 세력이 없던 이전 세이브는 이때 콘텐츠의 시작값으로 채운다 (`factions_initialized`)
- 밸런스 확인 (초안 수치, 시드 3개, 120일): A는 70명에서 40명 안팎으로 서서히 줄고, 동쪽 초소·강변·구시가가 오간다. C의 동쪽 공세는 열흘마다 온다

**플레이어가 겪는 방식 (정보 필터)**

- 자기 무리가 낀 교전은 보고(전해 들음)로 듣고 화면에 카드로 보인다. 다른 무리끼리의 일은 40% 확률로 소문이 된다. 믿음에 `topic: war`를 붙인다
- 사상자는 "한두 명 / 몇 명 / 여럿"으로만 전한다
- 다른 무리의 진짜 인원·자원·클락은 어디에도 나오지 않는다. 규모는 누구나 아는 시작 규모(약 N명)로만 말한다
- 자기 무리는 분위기(사기)·배급 수준(식량이 며칠 치인지)·창고 사정(대략)만 안다
- GM 컨텍스트에 "무리 사정"과 세력 관계를 넣고, 전황은 믿음으로만 알며 지어내지 않는다고 적는다
- `!세력`: 소속 무리 분위기·배급, 다른 무리의 공개 평판·관계·대략 규모, 최근 전황 5개. `!배급`: 오늘 배급, 창고 사정. 웹 캐릭터 시트에 "무리" 칸

**태도가 바뀌는 클락 (shift, 12-22)**

- 세력 사이 태도(`disposition`)는 세이브 상태에 있다 (시작값은 콘텐츠). 전쟁 시뮬레이션은 지금 태도로 적대(-2 이하)를 판단한다
- 세력 클락 `kind: shift`: 다 차면 공격 대신 정해 둔 태도로 바뀐다 (`shift: [{ from?, to, value }]`, `to: strongest` = 그때 전투원이 가장 많은 다른 무리). 한 번 일어나고 끝나며(찬 채로 남고 이야기로 되돌릴 수 없다), `news`가 소식으로 퍼진다 (그 무리나 대상 무리 사람은 전해 듣고, 아니면 소문)
- `post_apoc`: 버들마을 `b_waver`(연합에서 발 빼기, 30일: 청솔과 0, 붉은연합과 화해), 나루상단 `e_side`(이기는 쪽에 붙기, 35일), 하얀매 `d_lean`(가장 큰 무리에 약을 먼저 대기, 40일, 12-25). 이야기의 `clock` 효과가 당기고 늦춘다 (하얀매는 붉은연합의 독점 제안·도상필의 뒷거래가 당기고, 진료소 규칙을 지키면 늦춘다)

### 9.9 무리의 문화와 규율 (12-23)

무리마다 문화가 다르다: 어떤 무리는 군대처럼 규율이 빡빡하고, 어떤 무리는 이웃끼리 자율적이고, 어떤 무리는 계약만 있는 자유로운 무리다. core `game/culture.ts`.

- 규율 단계(수치)는 시나리오의 `discipline`, 무리마다 고르는 것은 `factions/*.yaml`의 `culture { discipline, summary, rules, address, punishment }`
- 규율이 정하는 것: 임무를 버리거나 기한을 넘겼을 때의 공적, 불복종으로 치는지, 진급에 허용되는 불복종 수, 불복종 행적의 무게(0이면 행적 없음, 목격자의 반응도 없다), 임무를 부르는 말

| 규율 | 버림/기한 초과 공적 | 불복종 | 진급 허용 불복종 | 행적 | 임무를 부르는 말 | `post_apoc` |
|---|---|---|---|---|---|---|
| 군율 strict | -3 / -3 | 센다 | 0 | 무겁게(3) | 명령 | 붉은연합 |
| 질서 orderly | -2 / -2 | 센다 | 1 | 2 | 명령 | 청솔형제단, 하얀매 |
| 느슨함 loose | -1 / -1 | 안 센다 | 3 | 가볍게(1) | 당번 | 버들마을 |
| 자유 free | 0 / -1 | 안 센다 | 제한 없음 | 없음 | 일감 | 나루상단 |

- GM은 상태의 복무 줄 아래에서 소속 무리의 문화(요약, 규칙, 호칭, 어기면)를 보고 NPC를 그 문화대로 연기한다. 그 무리 사람은 `?세력`에서 규칙을 본다
- 무소속이거나 문화가 없는 무리는 질서(지금까지의 규칙)
- 역할의 권한 `access` (12-26): `ration`이 있어야 무리의 배급을 받고, `mission_board`가 있어야 상관이 그날의 임무를 내놓는다. 비어 있으면 둘 다 있는 것으로 본다. 나머지(예: 하얀매 수습의 `treatment_room`)는 GM이 보는 특권이고, 이름은 시나리오의 `access_labels`

### 9.10 빚 (12-28)

- 캐릭터의 `debts`(세력 id → 양): 주인공이 그 무리 장부에 진 빚. 캐릭터의 것이라 계승하면 새로 시작한다. 0 아래로 가지 않는다
- 시작 빚은 역할의 `start_debt` (`post_apoc`: 나루상단 짐꾼이 상단에 12)
- 갚는 길: 임무의 `repays_debt`(완수하면 임무를 준 무리에 진 빚이 그만큼, 일부 완수는 절반), 이야기의 `debt { faction, delta }` 효과(빌리기 +, 물건·일로 갚기 -), 그 무리 사람에게 갚는다고 건넨 물건(`transfer_item.repay`, 시세의 75%. 표시가 없으면 선물이다, 12-237)
- 조건 `debt_gte`·`debt_lte`: 독촉, 빚쟁이 (`storylets/world_debt.yaml`: 장부에 다는 통조림, 장부꾼의 독촉, 빚 받으러 온 사내들)
- `?상태`와 GM 상태에 빚이 보인다. GM은 빚의 양을 지어내지 않고 일감·물건으로만 줄인다

### 9.11 지휘: 분대 명령과 지도부 회의 (12-31)

"보이지만 지휘하지 않는다"(9.2)에서 한 걸음 나간다. 분대장은 몇 사람을 움직이고, 간부는 무리의 방침을 바꾼다. 결과는 모두 코드가 계산한다 (원칙 2)

**분대 명령** (역할의 `squad`가 있을 때)
- 역할의 `squad`: 주인공 밑의 분대원 (NPC id). 같은 무리·같은 계급의 역할로 옮겨 오면(스카우트, 자유 시나리오) 그 역할의 분대를 이어받는다
- 역할의 `squad_mates`: 주인공이 분대원일 때 같은 분대의 다른 분대원 (분대장은 `commander`). 명령은 내리지 못하고 시트의 "분대" 칸에 분대장과 함께 보이기만 한다 (`post_apoc`: 청솔 하급 전투원, 버들마을 경비병, 붉은연합 약탈 삼조)
- GM tool `squad_order { members, task, zone }`: 분대원에게 일을 맡긴다. 일은 시나리오 `command.squad_tasks`에서 온다 (`post_apoc`: 보초, 수색, 정찰, 호위, 쉬게 하기, 따라오게 하기)
  - `follow`: 동행(7.8)이 된다. 곁에 있으면 공통 규칙 8(1.1)대로 돕고(그 판정을 잘하는 사람이 +1) 위험을 나눈다 (`command.follow_bonus`는 12-235부터 쓰지 않는다)
  - 그 밖의 일: 분대원이 그 구역으로 나가 정한 시간 동안 장면·배역에서 빠진다. 같은 사람에게는 한 번에 한 가지 일
- 따르는지는 코드가 정한다: 분대원이 주인공을 보는 존중이 -2 이하면 거절한다 (거절도 이벤트·행적이 된다). -1이면 늦게 나가 시간이 1.5배
- 결과는 시간이 다 되면 코드가 굴린다: 2d6 + 분대원의 능력 + 스킬(상한 +4) + 구역 위험(우리 땅 0, 빈 땅 -1, 적의 땅 -2) + 주인공의 지휘(전략) 스킬이 1 이상이면 +1
  - 성공: 일의 보상 전부 (무리 자원, 물건, 공적). 위험한 일을 해내면 존중 +1
  - 대가 있는 성공: 보상 절반
  - 실패: 보상 없음. 위험한 일이면 부상 한 단계 (부상 트랙 그대로라 이미 크게 다친 사람은 죽을 수 있다. 원칙 3), 주인공에 대한 신뢰 -1
  - 쉬게 하기: 호감 +1, 가벼운 부상 회복
- 주인공은 결과를 보고로 안다: 돌아온 분대원의 보고가 믿음(report)과 화면 표시로 남는다. 돌아오지 않은 사람은 "돌아오지 않았다"만 안다 (원칙 4: 어떻게 죽었는지는 모른다)
- GM 상태의 "분대" 섹션: 분대원마다 맡긴 일, 돌아올 시각, 마지막 보고

**지도부 회의** (계급이 `command.council_ranks`에 있을 때. `post_apoc`: 간부)
- 무리 방침: 시나리오 `command.policies`의 주제와 선택지 (`post_apoc`: 배급 — 줄이기·보통·늘리기, 태세 — 지키기·보통·밀어붙이기)
- GM tool `council_propose { topic, option, approach }`: 상관(지도부)이 장면에 있을 때, 주제마다 하루 한 번 안을 올린다. 판정 2d6 + 능력 + 스킬(approach: 교섭/전략) + 상관의 신뢰(+2 이상이면 +1, -2 이하면 -1)
  - 성공: 받아들여진다. 대가 있는 성공: 받아들여지지만 그 선택지에 반대하는 사람(`opposed_by`, 무리마다 섞어 적고 같은 무리 사람만 센다)의 신뢰 -1. 실패: 기각, 사흘 동안 같은 주제를 다시 올리지 못한다
- 세력 상태의 `policy`(주제 → 선택지)를 전쟁 틱이 읽는다: 소모 배수(`upkeep`), 공격 성향 배수(`aggression`), 방어 병력 배수(`defense`), 하루 사기 변화(`morale { delta, chance }`)
- 이야기 효과 `faction_policy { faction, topic, option }`로도 바뀐다 (지도부가 스스로 배급을 줄이는 날)
- 배급 방침은 개인 배급 단계에도 닿는다 (`ration_shift`: 줄이면 창고는 오래가고 각자 한 단계 덜 받는다)
- 무리 사람은 누구나 자기 무리의 방침을 안다 (GM 상태의 "복무·임무"). 다른 무리의 방침은 보이지 않는다
- **창고 전망** (12-139): 회의에 앉으면 GM 상태에 "지금 방침·이 계절대로면 줄어드는 자원이 약 며칠 가는지"와 선택지마다 바뀌는 날 수가 붙는다 (가진 구역의 산출 × 계절 × 일손과 소모 × 계절 × 방침을 맞댄 대략의 전망, 교전·교역 빼고. `stockOutlook`). GM 전용 숫자로, 지도부 사람이 말로 전한다. 자동 플레이 간부들이 겨울에 "넉넉히 때기"를 통과시켜 연료를 다 써 버린 것을 막으려는 것
- 이야기 조건 `own_policy { 주제: [선택지] }`: 방침을 겪는 사람들의 이야기 (`storylets/world_command.yaml`: 반 국자, 김이 오르는 솥, 출정 배웅, 회의의 겨울 장부·칠판 위의 화살표, 분대의 먼저 손을 든 사람·맞지 않는 보고)
- 분대는 그 자리(역할의 계급)에 있는 사람만 지휘한다. 분대원이 죽은 분대장을 이어받아 플레이하면 분대가 없다. 계승·무리 옮기기에서 명령·보고·회의 기록은 비운다
- 랜덤 자동 플레이가 분대 명령·회의 안을 섞어 돈다 (시나리오 8개 × 시드 5개 오류 0건)
- 다른 무리의 분대: 붉은연합 약탈조장(`role_c_squad_leader`, 간부 마경수 밑 사조 넷). 군율의 무리라 앞줄에 설 사람, 규율반의 귀, 탈영을 떠보는 조원 같은 이야기가 붙는다
- **교역 방침** (세력 자원 관리): 방침 선택지의 `trade { partner, fallback_partner, give, get, min_disposition }`. 전쟁 틱이 하루마다 상대 무리와 창고의 자원을 바꾼다. 상대가 자기 자신이면 `fallback_partner`와 바꾼다 (12-43). 서로의 태도가 기준 아래거나 어느 쪽 창고가 모자라면 그날은 하지 않는다 (`post_apoc`: 식량→탄약·연료→식량은 나루상단(나루상단 자신은 붉은연합·버들마을과), 물→의약품은 하얀매)

**분배 방침** (12-128): 자원 분배표(15.2)를 숫자 표 대신 회의 방침 주제 셋으로 넣었다. 어디에 더 쓰고 어디를 아낄지 고르는 결정은 같고, 기존 `council_propose`(판정, 반대하는 사람의 신뢰)를 그대로 쓴다. 숫자를 하나하나 옮기는 관리 게임은 대화 중심의 1인 TRPG와 맞지 않아 넣지 않았다
- 방침 효과 넷을 더했다: `firepower`(교전의 화력 배수), `ammo_use`(교전마다 쓰는 탄약 배수), `care`(무리 의무실이 하루 돌보는 사람 배수, 한 사람에 의약품 하나), `heated`(그 무리 거점의 불 땐 거처 최저 체감에 더하는 도)
- `post_apoc` (*임시*)
  - 탄약 분배: 아끼기(탄약 ×0.5, 화력 ×0.85) · 보통 · 전선에 몰기(탄약 ×1.5, 화력 ×1.2)
  - 의약품 분배: 아끼기(돌봄 ×0.5) · 보통 · 아낌없이(돌봄 ×2)
  - 연료 분배: 아끼기(연료 소모 ×0.6, 거처 -6°) · 보통 · 넉넉히 때기(연료 ×1.4, 거처 +4°, 하루 10%로 사기 +1)
- AI 무리는 지금처럼 보통에 머문다 (방침을 바꾸는 것은 주인공의 회의 안과 이야기 효과 `faction_policy`뿐). 그래서 `war:sim` 균형은 그대로다

**피난민** (12-133): 우리 거점 문 앞에 피난민이 온다 (`storylets/refugees.yaml`, 스무 날에 한 번쯤)
- 이야기 효과 `faction_population { faction, delta }`로 무리의 사람 수가 바뀐다. 전쟁 틱이 사람 수로 하루 소모(입)와 일손(구역 산출, 시작 인원 대비 0.7~1.2배)을 계산하므로 받아들이는 손익은 저절로 생긴다. 줄면 싸울 사람도 그 안으로 준다
- 간부는 직접 정한다 (모두 받기 — 들이기 전에 응급처치로 몸을 살피고, 놓치면 물린 사람이 섞여 구역 감염체 압력 +1·사기 -1 / 일할 사람만 / 돌려보내기 — 사기 -1). 다른 계급은 지도부에 말을 넣거나(설득) 몰래 먹을 것을 건넨다
- 받아들이면 며칠 뒤 그 가운데 다른 무리의 귀가 섞여 있었다는 이야기 (경계 판정, 놓치면 창고가 털린다)
- 전쟁 틱의 조용한 유입: 창고에 두 주 치 식량이 있고 사기가 -2 이상이면 하루 8%로 +1, 인원이 시작의 70% 아래면 16% (12-138. 전에는 사기 0 이상일 때만이라 밀리는 무리는 다시 늘 길이 없어 240일에 사라졌다)
  - 12-147: 식량만이 아니라 필수 자원(식량·물)이 모두 두 주 치 있고, **가장 어려운 계절의 하루 수지로도 60일을 버틸 때만** 든다 (`stockOutlook`을 계절마다). 비축만 보면 좋은 계절에 산출이 감당 못 할 만큼 사람이 몰렸다가 물·식량이 바닥나 한꺼번에 꺼졌다 (버들마을 360일 26명, 하얀매 480일 33명). 버들마을 물 42 → 50, 하얀매 물 33 → 38

**무리 안의 갈등** (12-134): 사기·창고가 가라앉으면 수군거림(9.13의 형편 이야기)이 실제로 터진다 (`storylets/conflict.yaml`, 우리 땅에서만)
- 비어 있는 자리 (사기 -2 이하): 밤사이 넷이 떠났다. 쫓으면(생존) 몇을 데려오고, 보내 주면 무리 사람 수 -4, 남은 사람을 모으면(설득) 사기 +1
- 부서진 자물쇠 (사기 -1 이하): 창고 도둑. 발자국을 쫓아 찾거나(경계), 의심 가는 사람에게 몰래 돌려놓게 하거나(설득), 끼지 않는다. 못 찾으면 식량이 줄고 서로 의심한다
- 배식 줄의 주먹 (사기 -1 이하): 뜯어말리기(싸움)·편들기·구경. 누구 편을 들었는지 관계로 남는다
- 반란 모의 (사기 -2 이하): 간부가 아니면 지도부 창고를 털자는 말에 끼거나 알리거나 거절한다. 끼면 며칠 뒤 그 밤(은밀): 통조림을 쥐거나, 붙잡혀 공적 -2. 간부면 아래의 말을 듣고 창고를 풀어 달래거나(식량 -10, 사기 +1) 주동자를 내쫓는다(위협, 놓치면 친구들이 함께 떠난다)
- 새 규칙은 없다. 피난민의 `faction_population`과 기존 효과(창고·사기·관계·행적·공적)로 만든다

**전쟁에 돌리는 몫** (12-139): 세력의 `war_share`(0~1, 기본 1). 나머지는 감염체와 게임에 나오지 않는 바깥의 적을 막는다고 보고, 먼저 치는 확률과 치러 내보내는 병력에 곱한다 (지킬 때는 다 쓴다). `post_apoc`: 붉은연합 0.6 (*임시*). 시드 12개 × 240일에서 청솔 인원 평균 15 → 35명(최소 3 → 25), 붉은연합 114명으로 여전히 우세
- **감염체 압력이 몫을 줄인다** (12-144): 그날의 몫 = 기본 몫 × (1 − 자기 땅의 압력이 기준값보다 높은 단계의 합 × `infestation.war_share_cut`), 기본 몫의 `war_share_floor` 아래로는 내려가지 않는다 (`warShareOf`). 감염체가 몰린 땅을 지키느라 남의 땅을 칠 사람이 준다. 모든 무리에 같다. `post_apoc`: 단계당 15%, 바닥 40% (*임시*). 240일 청솔 평균 35 → 42명(최소 34), 붉은연합 98명 (지원 방어 12-143 포함)
  - 플레이어가 적의 땅에서 총·오토바이로 소리를 내 물결을 깨우면 그 무리의 공세가 준다. 대신 **모든 무리는 자기 땅을 순찰한다**: 남의 땅에서 소음이 크면(2 이상) 그 땅 무리의 순찰조가 소리를 쫓아온다 (`wg_noise_patrol`, 급한 이야기: 둘러대기·감염체 쪽으로 끌고 달아나기·맞서기, 놓치면 그 무리에 붙잡힌다)

### 9.13 무리 형편이 입에 오른다 (12-105)

무리의 어려움이 숫자로만 있지 않고 사람들의 말이 되게 한다. 규칙은 core `engine/factionTalk.ts`, 말투는 월드 팩 `war.talk`.

- **도는 말** (`factionTroubles`): 주인공 무리의 분위기가 가라앉음 이하, 배급이 정량이 아님, 창고의 자원이 "빠듯하다"보다 나쁨, 주인공이 48시간 안에 들은 전황 소식(믿음). 주인공이 거점에서 느끼는 것과 들은 것만이라 정보 필터를 지킨다 (다른 무리의 사정, 숨은 사실은 없다)
- **GM 상태**: "무리 사람들 사이에 도는 말"로 실린다. 우리 땅 장면에 배경의 수군거림·불평·다독임으로 한두 마디, 턴마다 되풀이하지 않고, 없는 숫자를 지어내지 않는다
- **인물마다의 태도**: 장면의 같은 무리 사람 카드에 "무리 형편에 대해"가 붙는다. 트레잇이 가장 많이 겹치는 태도: 투덜댄다(냉소·탐욕·게으름·다혈질·지침·무뚝뚝), 다독인다(열성·다정·보호 본능·원칙주의·어머니 같음·넉살), 불안해한다(소심·신중·호기심·수다쟁이), 셈한다(냉정·계산적·꼼꼼·잔혹), 없으면 조심스럽게 입에 올린다 (*임시*)
- **다른 무리의 소문** (`spreadTroubleRumors`, 하루 한 번): 주인공이 말이 모이는 곳(`war.talk.rumor.zones`: 장터·휴게소·성당·정수장·구시가)에 있으면, 형편이 어려운 다른 무리마다 35%로 그 무리의 어려움 하나를 지금 형편 그대로 소문(믿음)으로 듣는다 ("붉은연합 쪽 식량 창고는 바닥이 보인다는 말이 돈다"). 같은 무리의 같은 말은 사흘 안에 다시 듣지 않는다. 진짜 상태에서 나오지만 주인공에게는 소문으로만 닿는다
  - **부풀림·헛소문·직접 확인은 뺐다** (12-185): 그곳마다의 부풀림 확률(10~50%), 멀쩡한 무리의 헛소문(10%), 그 무리 땅에 가면 소문을 확인하는 규칙이 있었다. 틀렸는지는 GM에게도 가지 않아 플레이에서 보이지 않았다
- **이야기** (`storylets/world_mood.yaml`, 7개, 우리 땅): 형편은 식량이 바닥나 갈 때 마루 밑에 숨긴 깡통·멀건 국, 사기가 가라앉았을 때 떠나자는 불가의 수군거림·일부러 부르는 노래. 전조는 밤에 담을 긁는 소리, 아침의 남쪽 담 밑 발자국, 총소리 뒤 담 너머의 그림자 (정체를 확정하지 않는다, 공포 `fright`)
- **전조와 압력** (12-123): 담을 긁는 소리·남쪽 담 밑의 발자국은 우리 구역의 감염체 압력(7.5.2)이 평소보다 높을 때만 열린다 (이야기 조건 `zone_overrun`). 총소리 뒤의 그림자는 그대로 총소리에 걸리고, 겁에 질려 허공에 쏘면(실패) 소음 2가 되어 다음 날 압력이 오른다. 압력이 2 이상이면 "담 밖에 모이는 것들"(7.5.2)로 이어진다
- **사람들도 형편을 안다** (12-124, 12-185에 바꿈): 말이 모이는 곳에 머무는 사람(이름 있는 인물은 지금 있을 곳, 엑스트라는 마지막으로 본 곳)의 카드에 "오가는 말로 아는 다른 무리 형편"이 붙는다. 그 자리에서 지금 형편으로 계산한다 (`heardRumors`). 예전에는 날마다 그 사람의 믿음으로 쌓아 90일에 이벤트가 250~350KB 늘었다

### 9.14 외교: 휴전과 포로 교환 (12-126)

간부는 다른 무리와 직접 협정을 맺는다. 규칙은 core `engine/diplomacy.ts`, 협정 종류와 대가는 월드 팩 `diplomacy` (*임시*). AI 무리끼리의 휴전은 12-146 (9.16), 동맹은 아직 없다

- **누가**: 지도부 회의에 앉는 주인공(9.11, 간부)이 다른 무리의 간부 이상(`envoy_level` 3)과 한 장면에 있을 때. GM tool `negotiate { pact, envoy, approach, stat, intent }`
- **협정** (`pacts`): 휴전(`truce`, 7일 동안 서로 치지 않는다), 포로 교환(`exchange`, 서로 잡고 있는 상대 무리 사람을 돌려보낸다. 그쪽에 붙잡힌 우리 사람이 있어야 꺼낸다)
- **판정**: 2d6 + 능력 + 스킬(`moves`: 교섭·위협·거짓말). 상황이 난이도가 된다 (합쳐 -2 ~ +2): 그쪽이 우리를 나쁘게 보지 않으면 +1, 깊이 미워하면 -1, 그쪽 형편(사기·배급)이 어려우면 +1, 전투원이 1.5배 이상이면 +1 · 3분의 2 이하면 -1, 협상 상대의 신뢰 ±1
  - 성공: 맺는다. 대가 있는 성공: 맺되 우리 창고에서 `cost`를 내준다 (휴전 식량 30, 포로 교환 의약품 5). 실패: 거절, 그쪽 태도 -1, `retry_days`(3일) 동안 그 무리에 다시 꺼내지 못한다
- **휴전의 작동**: 휴전 동안 두 무리의 태도를 적대 기준(-2) 바로 위(-1)로 올려 둔다. 그래서 전쟁 틱(서로 치지 않는다), 쓰러졌을 때 곁의 사람, 손님 난방이 고칠 것 없이 따라온다. 기한이 되면 하루 틱이 원래 태도로 돌린다 (그사이 다른 일로 바뀌었으면 그대로 둔다)
- **깨기**: 휴전 중에 주인공이 그쪽 사람을 치면(take_action의 target_harm) 휴전이 깨지고 두 무리의 태도가 `broken`(-3)이 되며, 배신 행적(공개)이 남는다
- **보이는 곳**: GM 상태의 "외교" (우리 무리의 휴전과 기한, 간부면 제안할 수 있는 협정), 주인공의 기억(맺은 협정, 끝난 휴전). 다른 무리끼리의 일은 없다
- 세계 상태 `pacts`, `negotiationBlocked`, 이벤트 `pact_made`·`pact_ended`·`negotiation_refused`. 세이브 형식 47

### 9.15 지원 방어와 흔들리는 연합 (12-143)

- **지원 방어**: 어떤 무리가 공격받으면, 지키는 쪽을 태도 +2 이상(`ALLY_AT`)으로 보고 치는 쪽과는 그렇지 않은 무리가 전투원의 10%(`ALLY_COMMIT`, *임시*)를 방어에 보탠다. 진 쪽의 손실은 보탠 만큼 나눠 진다. 태도를 바꾸는 계획(이탈·편들기)이 처음으로 실제 전력에 닿는다 (버들마을이 떠나기 전에는 청솔을 돕고, 나루상단·하얀매가 붉은연합 편에 서면 붉은연합을 돕는다)
- **힘의 저울로 차는 클락**: 태도가 바뀌는 계획의 `pull { toward, against }`. 날마다 찰 확률 = toward의 전투원 / (toward + against). 당기는 쪽이 강할수록 빨리 차고, 붙잡는 쪽이 강해지면 더디다. 붙잡는 쪽에는 함께 해 온 시간만큼 정(`bond`, 힘에 곱한다)을 둘 수 있다. `post_apoc`: 버들마을의 연합에서 발 빼기(붉은연합 쪽으로 당기고 청솔이 붙잡는다, bond 2). 전에는 늘 30일째였고, 시드 12개에서 41~59일
- **외부인 찾기** (분대 명령 `outsiders`): 분대원이 지정한 구역에서 여덟 시간 동안 떠도는 사람을 찾아 설득해 데려온다 (교섭·매력, 위험한 일). 성공하면 무리 인원 +2, 대가 있는 성공 +1, 실패는 빈손. 분대 일 보상에 `population`을 더했다
- 시드 12개 × 240일 (bond 2까지): 청솔 평균 35 → 38명, 붉은연합 114 → 100명

### 9.17 무리 안의 정치: 재판·지도부 교체·반란·추대 (12-152)

### 9.7 전선 되돌리기 (12-2)

C가 한 달 안에 분쟁 지대를 모두 차지하고 전선이 굳던 문제(17.1)에 대한 답. 플레이어가 우리 무리의 반격을 앞당기고, 그 반격 전투에 직접 나설 수 있다.

- **반격 클락**: 세력 계획(`plans`)에 `target_rule: frontier`. 다 차면 그때 맞닿은 적대 세력의 구역 중 **원래 우리 땅이던 곳 먼저**, 그다음 산출이 많은 곳을 친다 (빈 땅이면 차지, 거점은 고르지 않는다). A의 "반격 준비"(14일)
- **플레이어가 앞당기는 길**
  - 전선 임무(`missions[].advances`): 완수하면 클락 +N, 일부 완수는 절반. 전선 정찰 +2, C 보급 털기 +3
  - 정찰 이야기의 효과(`clock`): 고가도로 위 순찰조를 끝까지 지켜보면 +1, 투항자에게서 수용소 이야기를 들으면 +2
- **반격에 나서기**: 반격이 벌어지는 새벽에 목표와 맞닿은 우리 구역에 있으면 공격 쪽 전투 장면으로 차출된다 (9.5). 이기면 구역이 넘어온다
- **정보 필터**: 우리 무리의 계획은 대략으로만 들린다 ("말만 돈다 / 준비가 한창이라는 말 / 임박했다는 말", "목표는 OO이라는 말"). 임박하면 GM 컨텍스트가 "맞닿은 우리 구역에 있으면 함께 나설 수 있다"고 알린다. 다른 무리의 계획은 여전히 들리지 않는다
- 밸런스 (시드 3개, 120일): 화면 밖에서 A의 반격은 8번 중 2~4번 성공, 구역 주인이 9~12번 바뀐다 (전에는 한 달 뒤로 굳었다). 임무로 앞당기면 반격이 13번으로 늘지만 실패한 반격만큼 A의 사람도 준다. 플레이어가 전투 장면에서 판세를 바꾸는 것이 차이를 만든다
- 실제 확인 (MCP): A 거점에서 지내자 반격 소문이 "말만 돈다 → 준비가 한창 → 임박"으로 바뀌고, 11일차에 C가 동쪽 초소를 빼앗자 목표가 동쪽 초소로 바뀌었다. 15일차 새벽 "세력 A 쪽이 동쪽 초소를 친다. 당신도 차출됐다"로 공격 쪽 전투가 열렸다

### 9.5 전투 장면 (9-1): 교전 속의 한 사람

세력 틱의 교전은 보통 화면 밖에서 숫자로 끝난다. **플레이어가 그 자리에 있으면** 교전을 바로 결론 내지 않고 라운드 단위의 전투 장면으로 연다. 플레이어는 전투의 한 일원으로서 침투, 경보 차단, 측면·후방 공격, 폭약, 미리 깔아 둔 함정으로 판세를 바꾼다. 승패와 수치는 코드가 정하고, AI는 연출한다.

**구역과 이동 (장소 시스템의 최소 형태)**

- 캐릭터는 전선 구역 하나에 있다 (`playerZone`). 시작은 역할의 `start_location`, 없으면 소속 세력의 거점
- `take_action.move_to`: 인접 구역으로 이동한다 (이동 활동 30~60분). 코드가 인접과 전투 중 여부를 검사한다

**전투가 열리는 때**

- 하루 틱에서 정해진 교전 중 플레이어가 끼는 것은 바로 계산하지 않고 그날 새벽(04:00~05:30 사이)으로 **예정**한다
  - 방어: 공격받는 구역에 플레이어가 있다
  - 공격: 우리 무리가 공격하는 구역과 맞닿은 우리 구역에 플레이어가 있다 (차출)
- 예정 시각에 플레이어가 아직 그 자리에 있으면 전투 장면이 열린다. 자리를 떴으면 화면 밖에서 계산한다
- 빨리감기(잠·보초·기다림)는 예정된 교전 시각에 멈춘다 (끼어들기 `battle`). 자정을 넘기는 빨리감기는 자정에서 하루 틱을 돌린 뒤 이어 간다

**전투 상태 (코드)**

- 양쪽 병력, 전세(-5 ~ +5, 우리 편 기준), 경보(0 ~ 3), 플레이어 위치(전선 → 측면 → 적 후방), 라운드(10분, 최대 8), 남은 적 목표물, 양쪽 사상자
- 매 라운드: 플레이어 행동의 효과 → 배경 교전(남은 병력·사기·무너진 목표물로 전세 ±1, 진 쪽 사상자) → 끝났는지 검사. 플레이어의 한 수가 전세를 끝까지 밀면 배경 교전 없이 그 자리에서 끝난다 (결정타)
- 끝: 전세가 ±5에 이르거나, 라운드가 다 되거나(전세 부호로, 0이면 방어 쪽이 버팀), 플레이어가 빠지면(남은 라운드를 코드가 굴린다)
- 결과는 세력 상태에 그대로 들어간다 (사상자, 습격 약탈, 구역 점령, 사기)

**전투 중 플레이어 행동** (`take_action.battle`)

- 효과 종류·조건·크기는 시나리오 팩(`scenario.yaml`의 `battle`)에 데이터로 둔다. core는 위치·경보·전세·목표물·준비물이라는 틀만 안다 (중세 팩이라면 폭약 대신 기름 항아리)
- 효과마다: 쓸 수 있는 위치, 경보 상한, 필요한 아이템(소모 여부), 필요한 준비물(함정), **최소 몸의 위험**, 경보 0일 때의 기습 보너스, 판정 결과(성공·대가 있는 성공·실패)별 전세·경보·전진·적 사상자·목표물 파괴
- 초안: 버티며 싸우기(전선), 숨어들기(전진, 실패하면 경보), 경보 전에 해치우기(경보를 낮춤), 측면·후방 기습(경보 0이면 더 크게), 폭약(목표물 파괴, 폭약 소모), 함정 발동(미리 설치한 함정 소모), 물러나기
- 전투 효과는 반드시 판정을 함께 넣고, 몸의 위험은 효과의 최소 위험(`min_harm`) 이상으로 선언한다. 한 번의 행동이 한 라운드(10분)다. 잠·보초·기다림·이동은 할 수 없다
  - 처음에는 모든 전투 효과에 위험을 요구했는데, 실제로 돌려 보니 대가 있는 성공(7~9)마다 부상이 쌓여 세 라운드 만에 치명상이 됐다. 숨어들기·덫 발동은 대가가 경보·전세로 오는 행동이라 none, 근접 싸움은 light, 폭약은 heavy로 둔다
- 판정 없이 지나간 턴도 한 라운드가 흐른다 (배경 교전만)

**준비** (`take_action.prepare`)

- 전투 전에 우리 구역에 함정 같은 준비물을 설치한다. 필요한 아이템을 쓰고 판정이 성공·대가 있는 성공이면 그 구역에 남는다. 그 구역에서 열린 전투에서 함정 발동으로 쓴다

**결과와 보상**

- 전투가 끝나면 플레이어의 기여(효과로 바꾼 전세의 합)에 따라 공적을 받는다 (최대 3)
- 우리 무리가 낀 전투 결과는 보고로 남고, 공이 크면 "용기" 행적으로 기록되어 소문이 된다
- GM은 라운드마다 전세·경보·위치·쓸 수 있는 행동을 받아 연출한다. 승패·사상자·점령을 지어내지 않는다

**구현 메모**

- 상태: `playerZone`, `preparations`(구역별), `pendingClashes`, `battle`. 이벤트: `zone_moved`, `preparation_set`, `item_consumed`, `clash_resolved`, `battle_started`, `battle_round`, `battle_ended` (모두 기본값이 있어 이전 세이브와 호환된다)
- 규칙은 `core/sim/battle.ts`(라운드), 연결은 `core/engine/battleTools.ts`(예정·시작·라운드·끝·문구). 끝난 결과는 `applyBattleOutcome`으로 세력 상태에 넣는다 (사상자, 약탈, 점령, 사기, 탄약·의약품)
- 예정된 교전은 GM 컨텍스트·명령어·화면 어디에도 나오지 않는다. 전투가 열린 뒤에만 "전투 중" 블록이 생긴다
- 병력은 대략적인 말로만 ("열 명 남짓", "스무 명 안팎")
- 초안 콘텐츠: 위치 3(전선·측면·적 후방), 목표물 3(지휘하는 자·탄약 더미·기관총 자리), 준비물 1(철사 덫, 철사 뭉치 필요), 효과 7. 신병은 철사 뭉치를, 박만수는 사제 폭약을 갖고 시작한다
- `!지도`: 현재 구역, 맞닿은 구역과 주인, 설치해 둔 것. 웹 시트에 "있는 곳"과 전투 칸(전세 게이지·경보·위치)
- 실제 확인 (MCP, LLM 없이): 새 세계에서 동쪽 초소로 옮겨 덫을 깔고 기다리자 5일 뒤 새벽 C의 습격으로 전투가 열렸다. 덫 발동 → 숨어들기 ×2(측면 → 적 후방) → 소리 없이 해치우기(경보를 0으로) → 기습 ×2(두 번째에 발각) → 승리. 우리 쪽 사상자 1, 적 7, 공적 +2

### 9.5.2 매복과 전투 준비

전투 준비물이 철사 덫 하나뿐이었고, 작은 싸움(엑스트라·이름 있는 상대, 7.5)에는 준비할 길이 없었다. A(무리 전투 준비물)와 B(작은 싸움의 매복)를 넣었다.

**A. 무리 전투 준비물 늘리기** (12-176, 구현)

- 준비물에 `materials`(여러 재료, 판정 결과와 관계없이 쓴다), `holds`(막기), `infested_rise`(감염체 압력이 오를 확률)를, 전투 효과에 `keeps_preparation`(써도 남는다)을 더했다
- `post_apoc` (*임시*)

| 준비물 | 재료 | 쓰는 법 |
|---|---|---|
| 철사 덫 | 철사 뭉치 | 덫 발동 (한 번 쓰면 없어진다) |
| 모래주머니 엄폐 | 천 2 | 엄폐하고 버티기: 전선, 위험 none(크게 다치지 않는다), 실패해도 전세를 잃지 않는다. 써도 남는다 |
| 사격 자리 | 판자 1 | 자리 잡고 쏘기: 전선, 성공 전세 +2. 써도 남는다 |

- 전투 결과 줄: "밀고 들어오던 적이 바리케이드에 막혔다". GM 상태의 전투 블록에 "바리케이드가 버티는 중"
- **바리케이드는 거점 시설이다** (12-184에 합침, 4.8.3): 준비물 "길목 바리케이드"와 시설 "바리케이드"가 이름·재료가 같아 헷갈렸다. 시설 바리케이드가 이 구역을 **지키는** 전투에서 배경 교전에 밀릴 때 두 번 막고(전세도 사람도 잃지 않는다) 그 전투에서 부서진다(담 +1도 함께 사라진다). 서 있는 동안 이 구역의 감염체 압력은 오를 일이 있어도 절반 확률로만 오른다. 시설 효과 `holds`·`infested_rise`. 거점 밖 우리 땅(`own`)에도 짓는다
- 세이브: 전투 상태 `holds`, 이벤트 `battle_started.barrierUsed`·`battle_round.holds` (기본값이 있어 형식은 그대로)

**B. 매복** (12-177, 구현. 2026-11-18 로틴님 제안: 판정 +2, 확률로 상대 혼란, 적도 매복, 대신 어렵게)

- **내가 매복한다**: `take_action.ambush` + 판정(은밀). 보통 이하로 고른 난이도는 **어려움**으로 굴린다. 기다리려면 activity wait를 함께
  - 성공 = 12시간 매복. 이 구역에 나타난 상대에게 하는 **첫 공격(근접전·사격) +2**, 맞히면(실패가 아니면) 50%로 상대가 **혼란**
  - 대가 있는 성공 = +1만 (혼란 없음). 실패 = 자리가 드러나 서지 않는다. 한 번 치거나 구역을 떠나면 끝난다
  - **혼란에 빠진 상대**: 다음 판정 하나 동안 맞서지 못한다 (맞서는 상대 보정 0, 주인공이 실패해도 그에게 다치지 않는다)
- **적도 매복한다**: 이야기의 `ambush: true`. 열리면 상대가 먼저 움직인다 (4.1.1). 주인공의 **다음 판정 -2**(2시간 안), 그 판정이 실패하면 주인공이 **혼란**(다음 판정 -1)
  - 곁의 개가 냄새 맡기(12-172)를 알면 미리 알아챈다 (불리함 없음, "개가 먼저 냄새를 맡았다" 믿음)
  - `post_apoc` 이야기 셋 (`storylets/ambush.yaml`): 길목의 매복(위험한 길, 약탈자), 차 밑의 손(위험한 길, 감염체), 불빛을 노린 자들(위험한 곳의 야영, 모닥불)
- 보정은 판정 줄의 상황 보정으로 보인다: `+2(매복)`, `-2(매복당함)`, `-1(혼란)`. 다른 도구의 판정(흥정·탐험 등)에도 매복당함·혼란은 붙는다
- GM 상태의 전투 칸: "매복 중 (…까지)", "매복에 걸렸다", "…이(가) 혼란에 빠졌다"
- 월드 설정 `scenario.ambush` (*임시*): move stealth, hours 12, attack_moves [fight, shoot], bonus 2, partial_bonus 1, ambushed -2, confused -1, forewarn_trick sniff
- core `engine/ambush.ts` (판정 보정 `ambushParts`, 판정 뒤 정리 `afterCheckAmbush`는 `rollPlayerCheck`에서). 세이브 `ambush`·`ambushed`·`confused`

### 9.5.1 잠입 장면 (12-154)

전투 장면과 같은 틀로, 다른 무리의 땅에 몰래 들어가 일을 하고 나온다. 상태와 판정은 코드, 연출은 GM. 규칙은 core `engine/infiltration.ts`, 수치·목표는 월드의 `infiltration`

- **시작** (`infiltrate start goal`): 다른 무리의 땅(그 무리가 주인인 구역)에서. 목표는 월드 데이터 (`post_apoc`: 물자 빼내기·갇힌 사람 풀어 주기·망가뜨리기·엿듣기). 갇힌 사람 풀어 주기는 그 구역에 그 무리가 가둔 사람이 있을 때만
- **상태**: 깊이(`depths`: 담 밖 → 담 안 → 깊은 곳)와 경보(0~3). 한 걸음에 10분. 잠입 중에는 다른 구역으로 옮기거나 오래 머물지 못하고(빠지기부터), 다른 이야기가 끼어들지 않는다
- **전진** (`advance`): 은밀 판정. 성공·대가 있는 성공이면 한 칸 들어가고(대가 있는 성공은 경보 +1), 실패면 못 들어가고 경보 +2. 낮에는 어렵고, 밤이나 비·안개에는 쉽다
- **경보는 보이지 않는다**: 경보는 세계의 진짜 상태라 GM에게도 숫자가 가지 않고, 2 이상이면 보이고 들리는 낌새로만 간다 (원칙 4). 판정 결과는 다른 판정처럼 보인다
  - 은밀 판정의 결과를 숨기는 안(은밀은 적의 입장이라 "🎲 은밀: 판정 결과는 알 수 없습니다")을 넣었다가, 다른 은밀 판정과 맞추려고 일단 둘 다 보이게 했다 (12-154)
- **살피기** (`listen`): 경계 판정으로 한 걸음 멈춰 살핀다. 성공이면 경보를 말로 정확히, 대가 있는 성공이면 대략, 실패면 모른다
- **목표** (`act`, 가장 깊은 곳에서): 목표마다 판정 스킬(수색·은밀·급조). 성공이면 다 얻고, 대가 있는 성공이면 물건·자원은 절반에 경보 +1, 실패면 경보 +2. 효과는 이야기 효과로 적용한다 (물건, 그 땅 주인 무리의 자원·사기, 갇힌 사람 풀기, 엿듣기). 목표의 판정은 손에 잡히는 일이라 보인다
- **들킴** (경보 3): 빠지기만 된다. 그 무리의 태도 -1, 주인공의 "몰래 들어갔다 들켰다" 행적
- **빠지기** (`leave`): 경보 0이면 판정 없이. 아니면 은밀 판정, 가장 깊은 곳이거나 들켰으면 한 단계씩 어렵다. 실패하면 그 무리에 붙잡힌다 (포로 7.6)
- **보이는 곳**: GM 상태의 "잠입 중" 블록 (구역, 깊이, 목표, 낌새, 할 수 있는 것). 잠입하지 않을 때 다른 무리의 땅이면 "잠입할 수 있는 목표" 한 줄
- 넣지 않은 것: 잠입 안의 싸움 규칙(기존 판정·전투로 넘긴다), 경비 인원·순찰 경로 같은 지도, 상태 화면의 잠입 칸, 은밀 판정 결과 숨기기. 세이브 형식 59

**계급이 오르면 (2차)**

- 같은 전투 상태 위에서 분대장은 분대(동료 NPC)에게 명령하고, 간부는 라운드마다 병력 배치·전술을 바꾼다. 적도 코드의 전술 표로 대응한다
