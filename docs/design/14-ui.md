## 14. UI

- 화면은 Claude 앱의 채팅이다. GM이 서술하고, 선택은 클릭 도구(Claude Code의 `AskUserQuestion`)나 자유 입력으로 한다
- 상태·지도·관계 같은 정보는 `?` 정보 명령어의 텍스트 출력으로 본다 (11.7)
- 상태 화면 (11.6): 앱의 브라우저 패널에 띄워 두는 읽기 전용 캐릭터 시트 (능력, 스킬, 레벨, 몸 상태, 소지품, 임무, 관계)
- 캐릭터 생성은 채팅에서 대화로 한 단계씩 (4.2)
- 사망 → 묘비명 → 연대기 → 다음 캐릭터 선택도 채팅에서
- (웹 앱 화면은 12-14에 폐기, 11.5)
