## 15. MVP 범위

### 15.1 포함

| 항목 | 범위 |
|---|---|
| 시작 역할 | A의 분대원 (고정) |
| 세력 | 5개 (A, B, C, D, E), 전쟁 진행 중 |
| 장소 | 12~15곳 (세력 영역 + 분쟁 지대), 노드 그래프 |
| 주요 NPC | 15~20명, 플레이 가능 수준 스키마 (A 분대 동료 포함) |
| 판정 | 2d6, 기본 행동 7개, 개인 전투, 부상 트랙 |
| 임무 | 배정 → 수행 → 보고, 명령 불복종 반영 |
| 진급 | 분대원 → 분대장 (공적, 상관 신뢰, 생존 기간) |
| 자원 | 5종, 일일 소모, 배급 |
| 시간 | 행동 비용, 이동 빨리감기 + 끼어들기 |
| 정보 | Belief State 기본 |
| 평판·소문 | 행동 태그, 보이는/숨은 목격자, 하루 단위 1단계 전파, 가치관 기반 관계 변화 |
| 전쟁 | 세력 단위 추상 시뮬레이션 + 개인 단위 체험 |
| 시나리오 | 고정 스토리렛 10개 + 템플릿 15~20개, 세력 클락, 계절 |
| 사망·계승 | 아이언맨, 연대기, 다음 캐릭터 선택 (기존 NPC 포함) |
| 저장 | 세계 세이브, 이벤트 로그 |
| RAG | lore·memory 컬렉션, 정보 필터를 따르는 하이브리드 검색(sqlite-vec + FTS5, RRF), 검색 평가 세트 (11.4) |
| 시나리오 팩 | 장르 요소를 `post_apoc` 시나리오 설정으로 분리 (12.3) |

### 15.2 제외 (2차 이후)

- 세력 자원을 하나하나 옮기는 숫자 분배표 (분배는 12-128에서 회의 방침 주제로 넣었다, 9.11). 분대 명령·지도부 회의·교역 방침은 12-31·12-33에서 넣었다 (9.11)
- 다른 시작 역할
- 대규모 전투, 외교
- 소문 왜곡, 세력 간 전파, 소문 조작
- 교역망과 복잡한 경제
- 연애
- 두 번째 시나리오 팩, 규칙 자체의 플러그인화

### 15.3 완성 기준

- 분대원으로 시작해 여러 날을 생존하며 임무, 소문, 관계, 전쟁의 영향을 체감할 수 있다
- 사망하면 연대기가 남고, 같은 세계에서 다른 캐릭터로 이어서 플레이할 수 있다
- 중간에 종료해도 이어서 플레이할 수 있다
