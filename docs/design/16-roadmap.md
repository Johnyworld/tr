**2차**
- 분대장·간부 콘텐츠: 분대 명령, 회의 방침, 교역, 붉은연합 분대는 들어갔다(9.11). 분배는 회의 방침으로 넣었다(12-128). 남은 것은 다른 무리(버들마을·하얀매·나루상단)의 간부 시나리오
- 시작 역할 선택 (혼자 / 외부 무리 / A~E 일원 / 간부)

- 무리 단위 전투, 외교

**3차**
- 연애 요소
  - 성격 태그 궁합으로 관계가 빠르게 오르거나 내려감 (AI는 대화를 태그로 분류, 수치는 코드)
  - 관계 단계: 낯선 사람 → 동료 → 친구 → 호감 → 연인
  - 연애 대상은 이성 간으로 한정 (NPC 데이터의 연애 가능 필드로 설정)
  - 연인이 위험 요소가 되는 전개 (부상, 포로, 명령과의 충돌), 연인으로 계승

- 두 번째 시나리오 팩 (예: 중세 판타지)과 그에 필요한 규칙 플러그인화
- 배포 형태 결정: 로컬 MCP 배포(npm 패키지·Claude Code 플러그인·`.mcpb`) 쪽으로 검토 중. 검토 내용은 `docs/deployment.md` (아직 결정 전)
