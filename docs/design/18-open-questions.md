## 18. 미정 사항

- 도시 이름, 지명, 장소 목록 (전쟁 구역 초안 9곳만 있음: 9.4)
- 세력 A, B, D, E의 성격 확정 (현재 초안). 세력 수치와 구역 산출은 *임시* (9.4)
- 세력 리더와 주요 NPC 명단 (A 거점 초안 NPC 6명만 있음: 7.4)
- 능력·스킬, 성장, 몸 상태 수치 확정 (현재 *임시* 값으로 구현: 4.1, 4.2, 4.4, 4.5)
- 진급 조건 수치 (현재 *임시* 값으로 구현: 8.6)
- 행동별 소요 시간 테이블 (현재 *임시* 값으로 구현: 5.1)
- 사용할 Claude 모델 구성 (서술용 / 분류·요약용)
