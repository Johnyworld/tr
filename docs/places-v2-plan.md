# 장소 개편: null 없애기, 이웃 목록, 길 장소 (계획)

2026-11-23 사용자와 정함. **구현 끝: 12-274** (B④는 이 위에서 다시 권장). 공통 규칙 15(장소)의 다음 단계. B④(시간대마다 장면 비우기)보다 먼저 한다 (④가 장소 개념 위에 서기 때문).
배경: `docs/place-unknown-plan.md` (장소 null의 세 뜻, 구역 밖 일과 49칸).

## 정한 것

1. **장소 null을 없앤다.** 주인공·인물은 늘 어떤 장소에 있다. 대신 "구역에 없음(나가 있음)"은 구역 쪽 개념으로 남는다
2. **장소 사이는 좌표가 아니라 이웃 목록.** 좌표는 담·벽을 모른다. 좌표는 지도 화면이 필요할 때 따로 더한다
3. **구역 안의 길도 장소다** (동쪽 길, 9번 국도 등). 길은 바깥, 이어지는 구역(`to`)을 적는다. 구역에 들어오면 그 길에 도착한다 ("막 들어선 자리"를 대신)
4. **숨은 목격자는 근처만:** 같은 장소 ×2(12-271 그대로), 이웃 장소 ×1, 그 밖 0. "구역 어딘가"는 없어진다. 벽 사이 가르기는 하지 않는다
5. **구역 밖 일과(A안)를 함께 넣는다:** 일과 칸이 `routine_away` 말이면 그 시간대엔 구역에 없음 (place-unknown-plan.md A안. 주인공의 분대원은 예외, 장면에 들이려 하면 경고만)
6. **잠입 깊이는 gate로 센다** (2026-11-23 사용자 결정, 처음 안 "길에서 몇 칸"을 고침: 바깥 장소를 늘리자 초소가 길에서 한 칸인데 담 밖이었다). 담을 지나 처음 닿는 장소에 `gate: true`. 길에서 gate를 거치지 않고 닿는 곳 0, gate 1, gate 너머 1 + 칸수(2에서 멈춤). gate 없는 구역은 길에서 몇 칸. 잠입 중 이동도 이웃으로만(더 깊은 이웃 = 한 칸 들어감, 같은 깊이 = 숨기 판정만). 12-273의 실내외 어림을 대신한다
7. **장소를 넉넉히** (사용자): 이웃 구역마다 길, 바깥 장소(초소·쪽문 밖·검문 줄). 길 이름은 행선지로. 구역별 표는 `docs/places-v2-zones.md`

## 데이터 모양

```yaml
places:
  - { id: east_road, name: 동쪽 길, indoor: false, road: true, to: [a_east_post, old_town], near: [yard_gate] }
  - { id: yard_gate, name: 운동장·정문·담장, indoor: false, near: [east_road, mess, barracks, storehouse, stockade] }
  - { id: mess, name: 식당 천막, indoor: true, near: [yard_gate] }
```

- 이웃은 장소마다 `near`에 적는다(관계를 따로 두는 표가 아니라 그 자리에 적는 방식). 로더가 양쪽으로 맞춘다(A가 B를 적으면 B도 A의 이웃). content:check는 없는 id, 이웃 없는 장소(외딴 섬), 길 없는 구역, 길의 `to`가 지도 길(routes)과 맞지 않는 것을 잡는다
- 즉흥 장소(spawn_place)는 만든 자리의 이웃으로 저절로 이어진다
- 떠도는 인물은 그날 구역의 길(첫 길) 장소, 엑스트라는 처음 들인 장소, 분대 일 나간 사람은 그 구역의 길

## 늘어나는 것 / 줄어드는 것

- 콘텐츠: 21개 구역에 길 장소 1~3개씩, 모든 장소에 near, 길에 to. 장소가 없는 구역에도 길 하나 이상
- 규칙(rules/place.ts): `neighbors`, `stepsBetween`(깊이·이동 시간), 도착 길 고르기. 장소 사이 이동은 이웃 5분, 한 칸마다 5분
- 지울 것: `ENTRY_PLACE`와 null 예외(이야기 실내외의 막 들어선 자리, `storyPlaceOnEntry`, `atWaitingSpot`의 null, `sharesPlace`의 null, 바닥 물건 구역 열쇠, 불 `fireSpot`의 구역 열쇠, `searchSpot`), 실내외로 깊이 어림(`depthAt`), "구역 어딘가" 판정
- 세이브: 형식 바뀜, 하위 호환 없이 `SAVE_SCHEMA_VERSION` 올림 (12-244 때처럼)
