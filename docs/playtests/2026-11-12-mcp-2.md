# MCP 모드 플레이 테스트 2 (2026-11-12)

- GM: 이 저장소를 만든 Claude Code 세션(Opus 5.5). MCP SDK 클라이언트로 `trpg` MCP 서버를 띄워 tool만 호출했다. `play` 프롬프트로 GM 지침을 받았다
  - 1회차와 달리 **GM이 콘텐츠를 이미 안다** (스토리렛 조건, NPC 비밀 등). 그래서 "GM이 무엇을 모르고 헤맬지"는 이번 테스트로 알 수 없다. 흐름·tool 결과·상태 일관성 위주로 봤다
- 세계: `w20261112-111229-fac7` (`start_session {new_world: true}`)
- 진행: 23턴 + 빨리감기. 1일차 05:30 → 3일차 05:32 (사망) → 민서연으로 계승
- 결과 요약: 12단계 콘텐츠(NPC 16, 구역 12, 스토리렛 25)와 9-1·10·11단계 시스템이 한 판 안에서 이어서 돌아갔다. 임무 → 이동 → 덫 → 스토리렛 → 치료 → 새벽 전투 → 전사 → 묘비명 → 계승까지 끊김 없이 진행됐다. 다만 **장면 인물과 스토리렛의 수명**(구역을 옮겨도 따라다님, 전투 중에도 남음), **잠을 깨우는 사소한 이야기**, **세계를 열자마자 끼어드는 이야기** 같은 연결부 문제가 나왔다
- 하네스 실수: 처음 세계(`w20261112-111131-6be7`)에서 같은 턴을 두 번 보내 캐릭터가 이유 없이 다쳤다. 게임 문제가 아니라 테스트 스크립트 문제라 그 세계는 버리고 새 세계로 다시 했다

## 2. 잘 된 점

- **한 판 안에서 시스템이 서로 맞물렸다.** 임무 보초가 이야기로 끊기고, 깔아 둔 덫이 사흘 뒤 전투에서 효과로 나오고, 다친 몸을 다른 무리의 치료사에게 고치고, 그 몸으로 다시 전투에 나가 죽고, 그걸 본 동료로 이어 갔다
- **오류 문구가 다음 행동을 알려 준다.** 받을 수 없는 임무, 가진 것 없는 거래, 다친 데 없는 치료 모두 이유와 대안을 돌려줬다
- **구역의 낯선 사람**: 낌새("인기척")를 그 구역 사람으로 풀 수 있었고, 모르는 인물이 등장하면 그때 이름이 붙는 흐름이 자연스러웠다
- **전투 장면**: 덫 → 숨어들기 → 경보 → 기습의 흐름이 숫자 없이 "전세 우세/밀림, 경보 낌새/발각"으로 전달돼 서술하기 좋았다
- **계승**: 새 캐릭터의 컨텍스트에 이전 캐릭터의 기억이 새지 않았다 (`!일지` 비어 있음, recall은 그 인물이 직접 본 것과 소문만)

## 3. 문제와 처리

| # | 종류 | 문제 | 처리 |
|---|---|---|---|
| P1 | 설계 | 세계를 열자마자(0분) 이야기가 끼어든다 | 수정: `storylet_pacing.first_after_hours`(기본 2시간). 캐릭터 이야기가 시작된 뒤 그만큼 지나야 첫 이야기 |
| P2 | 콘텐츠 | A 대원이 거점 대표·취사 담당을 모른다 | 수정: 역할의 `known_npcs`에 추가 |
| P5 | 문구 | "철사 덫을(를)", "호감이(가)" 같은 조사 | 수정: 코드의 고정 조사를 `josa()`로 |
| P6 | 콘텐츠 | 판정 실패 효과가 빈 선택지는 대가를 GM 서술에만 맡긴다 | 남김: 서술로 충분한 경우가 많다. 12단계 이후 콘텐츠를 다듬을 때 실패 효과를 채운다 |
| P10·P13·P14·P18 | **버그** | 장면의 인물이 구역을 옮겨도 따라오고, 끝난 이야기의 배역이 남고, 이야기가 다른 구역까지 따라온다 | 수정: 구역을 옮기면 장면 인물은 남고(동행은 다시 등장), 그 자리 이야기는 끝난다. 이야기가 시간이 지나 끝나면 그 때문에 들어온 배역은 떠난다 |
| P11 | 설계 | 사소한 이야기가 잠을 깨운다 | 수정: 스토리렛 `urgent`. 자는 동안에는 급한 것만 깨우고(감염체 침입, 초소 아래 소리, 투항자, 탈영 제안), 나머지는 깬 뒤에 열린다 |
| P12 | 콘텐츠 | 배급 줄·화투판 이야기가 초소에서 열린다 | 수정: 거점(a_base)에서만 |
| P15 | 콘텐츠 | 상인 문구 "두 갑" ≠ 효과 한 갑 | 수정: "한 갑" |
| P16 | 설계 | 적의 땅에 있어도 컨텍스트에 표시가 없다 | 수정: 현재 구역이 적대 세력의 땅이면 GM 컨텍스트에 경고 한 줄 |
| P19 | 버그 | 전투가 열려도 진행 중이던 이야기가 남는다 | 수정: 전투가 열리면 이야기는 끝난다 |
| P21 | 버그 | 전투 중 사망하면 전투 결과(승패·사상자)가 tool 결과에 없다 | 수정: 사망 문구 뒤에 전투 결과를 붙인다 |
| P22 | 설계 | 다음 캐릭터 후보에 다른 세력 인물이 들어간다 (역할 규칙이 A 하급 전투원 것이라 어긋난다) | 수정: MVP는 같은 무리 사람만. 다른 세력으로 이어 가기는 역할 선택(2차)과 함께 |
| P24 | 설계 | 플레이어가 전투 중 죽으면 계승한 동료가 그 전투 결과를 모른다 | 남김: 보고가 살아 있는 플레이어에게만 간다. 계승 때 최근 전황을 넘기는 방법을 따로 정한다 |
| P0 | 비용 | `start_session`이 `play` 프롬프트와 같은 GM 지침을 한 번 더 돌려준다 (약 4천 자) | 남김: 1회차에서 프롬프트를 못 보는 환경이 있어서 넣은 것이다. 프롬프트를 쓴 세션이면 생략하는 옵션을 나중에 검토 |
