# MCP 모드 플레이 테스트 3 (2026-11-18)

- 목적: 오늘 넣은 12-156~169 (몸에 남는 상처, 술·진통제·마약, 유품, 수술, 약속, 쉬는 시간, 탐험할 곳, 장례·무전기, 다짐, 거점 손보기, 인물의 자기 일, 큰 재난)이 MCP 서버를 거쳐 한 판 안에서 도는지
- GM: 이 저장소를 만든 Claude Code 세션(Opus 5.5). MCP SDK 클라이언트로 `pnpm mcp`를 새로 띄워(새 코드) tool만 호출했다. 세계는 core로 만들고(`WorldManager.create`) 서버에서 불러왔다. 세이브는 임시 폴더, `RAG=off`, `TRPG_STATUS=off`, `TRPG_DEBUG=1`(치트로 시간·장면을 당겼다)
- GM이 콘텐츠를 안다. 흐름·tool 결과·상태 일관성 위주로 봤다
- 세계 둘: 청솔 수색대원 "한별"(비극의 고리, 83일차까지), 떠돌이(구시가)

## 2. 문제와 고친 것

| | 문제 | 고친 것 |
|---|---|---|
| P1 | 닿는 다짐(떠나기·돌아가기)이 처음부터 그곳에 있으면 바로 이뤄진다 | 그곳을 한 번 떠나 있어야 닿은 것으로 친다. 떠돌이의 다짐은 "아파트 단지(버들마을)의 우리 집"으로 |
| P2 | 다짐 보상 경험치 60이 성장 곡선(5부터 ×1.3)에 비해 과하다 | 12 (초반 두 레벨쯤, 중반부터 한 레벨 안쪽) |
| P3 | 어긴 약속이 소식으로만 지나가고 기억에 남지 않는다 | 믿음으로 남긴다 ("…의 기한이 지났다. 지키지 못했다") |
| P4 | 다짐·지을 수 있는 시설·재난 줄이 "캐릭터 상태" 덩어리에 있어 시각이 바뀔 때마다 다시 실린다. 시설 줄이 재료까지 길다 | 덩어리를 따로 두었다 (주인공의 다짐·시설·재난). 시설 줄은 id와 판정만, 재료는 짓겠다고 할 때 오류 문구로 |
| P5 | 탐험 중 깨어난 감염체가 장면에 있어도 더 내려가고 뒤질 수 있다 | 깨어난 것이 앞에 있으면 싸우거나 빠져나오기만 |
| P6 | 재난 소식 "동쪽 초소에 감염체 떼의 이동 (청솔형제단)"이 어색하다 | 재난마다 소식 문장 (`news`: "감염체 떼가 동쪽 초소를 덮쳤다") |
| P7 | 조사가 그대로 나온다: "기록실 복도은(는)", "민서연이(가) 붉은연합과(와)의" (뒤의 것은 예전 포로 소식) | 조사 함수로 |

## 3. 확인하지 못한 것

- 갚기의 성공 경로(단계가 오르는 것)는 주사위가 따라 주지 않아 이번 판에서는 못 봤다 (단위 테스트로는 본다)
- 장례·유품·흉터·쉬는 시간·무전기·거점 시설의 효과(물·불·텃밭)·재난의 무너짐은 이번 판에서 열리지 않았다 (단위 테스트로만)
- 상태 화면(임무 칸 아래의 다짐)은 `TRPG_STATUS=off`로 띄우지 않아 보지 못했다
