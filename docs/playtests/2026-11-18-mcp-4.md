## 4. 확인하지 못한 것

- 부탁을 어겼을 때(기한 지남), 포상의 "형편이 나쁘면 말뿐"은 이번 판에서 열리지 않았다 (단위 테스트로만)
- `pnpm test:slow`의 role_a_grunt 자동 플레이가 "그 시나리오의 이야기 2개 이상"에서 1개로 떨어졌다 (12-178부터). 시드 11에서 붙잡힌 주인공이 크게 다친 몸(판정 -4~-7)으로 무거운 위험을 건 탈출을 거듭하다 두 번 죽었다. 자동 플레이가 중상 이상이면 탈출하지 않게 고쳤다 (12-180). 시드 열 개로 재면 분대 이야기는 시드마다 4~10개
