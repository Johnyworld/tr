# MCP 모드 플레이 테스트 4 (2026-11-18)

- 목적: 3회차 뒤에 들어간 12-170~178 (얼굴만 아는 원수, 포상, 개 기르기, 무전 송출, 부탁, 가축, 할 일 칸, 전투 준비물·매복, 낡은 정보·포로 심문·인물끼리 관계 치트·아이들·믿음)이 MCP 서버를 거쳐 한 판 안에서 도는지
- GM: Claude Code 세션(Opus 5.5). 3회차와 같은 하네스로 `pnpm mcp`를 새로 띄워 tool만 호출했다. 세이브는 임시 폴더, `RAG=off`, `TRPG_DEBUG=1`. 치트는 원하는 장면까지 빨리 가는 데만 쓰고, 그 장면의 판정은 그대로 굴렸다
- 세계 셋: 청솔 수색대원 "한별"(비극의 고리, 31일차까지), 떠돌이(구시가, 5일차까지, 상태 화면 확인), 청솔 수색대원(부탁·포로 심문·장례·아이들·믿음, 11일차까지)

## 2. 문제와 고친 것

| | 문제 | 고친 것 |
|---|---|---|
| P1 | 실종 정찰조(오정빈·남궁혁)의 평판이 "붉은연합 수용소에 갇혀 있다"고 진짜 행방을 말한다 (원칙 4) | 평판에서 뺐다 ("다리를 다쳤다는 말이 마지막 소식") |
| P2 | `josa("\"염철구\"")` → `이(가)` | 닫는 따옴표·괄호 앞 글자로 읽는다 |
| P3 | 되풀이되는 이야기가 같은 믿음을 또 쌓는다 | 이야기 효과의 믿음은 같은 문장이 있으면 쌓지 않는다 (전황 보고처럼 따로 일어난 일은 그대로) |
| P4 | 이름을 안 뒤에도 배경 믿음 "(이름은 모른다)"가 남는다 | 믿음으로 남기는 배경 문장에는 붙이지 않는다. 지난 일 줄은 그때그때 만들어 붙는다 |
| P5 | 코드에 박힌 조사: "권총을(를) 손에 들었다", "구시가을(를) 거처로", "누렁이이(가) 보초를", 휴전 소식 "과(와) …가", 시세 "연료이(가)", 버팀 "한별은(는)" 등 | 코드 120곳을 `josa()`로 |
| P6 | 우리 거점 안에서 묶은 포로가 끌려다니기만 한다 | 그 자리에서 우리 무리의 포로로 가둔다 |
| P7 | 묶어 끌고 가던 포로가 신뢰 바닥이라며 떠난다 | 포로는 관계로 떠나지 않는다 (동물처럼) |
| P8 | 주인공이 모르는 곳의 죽음으로 갚기가 "이뤘다"가 된다 | `gone`은 주인공이 알 때만: 유해가 있는 구역에 있거나(눈앞의 죽음, 시신을 찾음) 우리 무리가 가뒀다 |
| P8+ | (고치다 찾음) 이름 있는 인물이 눈앞에서 죽어도 유해는 그 사람의 평소 자리(일정의 구역)에 남는다 | 장면이나 곁에 있던 사람은 지금 구역에 남는다 |
| P9 | 전투 준비물과 거점 시설이 둘 다 "바리케이드" (재료도 같다). 전투 문구에 "바리케이드"가 core에 박혀 있다 (원칙 7). 준비물이 없을 때 id가 나온다 | 준비물은 "길목 바리케이드", 문구는 월드 팩의 holds 준비물 이름으로, 막힘 이유는 이름으로 |
| P10 | 시설 짓기가 더 걸린 시간이 결과 줄에 없다 | "짓는 데 1시간이 더 들었다" |
| P11 | 무전 장사꾼: 만날 자리를 정해도 아무 일 없다. 판다는 소금·실·건전지는 월드에 없다 | 강변 공장 지대로 나가면 짐꾼(e_porter)을 들여 흥정하라고 연출에 적고, 파는 것을 있는 것(통조림·담배·약)으로 |
| P12 | 콘텐츠의 박힌 조사 `{raider}을(를)`, `{leader}은(는)`, `{keeper}는`, 분대 보고 `{zone}을(를)` | 콘텐츠 390곳을 `{x:을/를}`로. 분대 보고·전쟁 소식도 `fill`로 채운다 |
| P13 | 매복 문장이 약탈자를 "사내"로 못박는다. 길이 아닌 곳에서 열리면 `{to}`가 그대로 | `{raider:이/가}`로, 길이 아니면 `{from}`·`{to}`를 지금 구역으로 |
| P14 | 떠돌이가 가죽 재킷을 입지 않고 시작한다 (autoEquip이 무기·외투만) | 몸·머리·팔도 가진 것 중 가장 잘 막는 것을 입는다 |
| P15 | 죽은 사람이 "아직 별일 없는 사이" 목록에 사망 표시 없이 | 죽거나 떠난 사람은 상태가 붙는 줄로 |

## 3. 관찰 (고치지 않았다, 정할 것)

- 임무에 장소 조건이 없다: 거점 안에서 "동쪽 초소 보초", "전선 정찰"을 완수했다 (예전부터)
- 분대장으로 진급했는데 상관이 여전히 분대장 강태호다
- 다짐 문구 "…에게 갚는다 (대상: …)"가 대상을 두 번 말한다
- 최근 믿음 10개 중 절반이 "…와 마주쳤다. 이름은 모른다. 겉모습: …" 긴 줄이라, 원수 같은 중요한 믿음이 "더 오래된 것"으로 밀린다
- 인물 목록의 "· 사망" 표시는 주인공이 모르는 죽음에도 붙는다 (GM에게 보인다, 예전부터)
- 무소속인데 `?임무`가 "상관에게 물어보세요"
- 개 훈련(생존)에 "+1(낚시 도구)"가 붙는다, `?인물 누렁이`와 상태 화면에 rank loner가 "혼자"로 나온다
- 뒤집힌 버스의 아이: 대가 있는 성공이면 "이름만 말하고 울었다"로 이야기가 끝나 아이를 둔 채 막힌다
- 의식불명이 되자 "앞으로 판정에 +0 보정을 받는다"
- (치트만) `~summon extra c_raider`는 틀 이름 "붉은연합 약탈조원 — 쇠지렛대"를 호칭으로 쓴다. 다짐이 없을 때 `~storylet rp_revenge_rumor`는 "배역을 채울 인물이 없다"

## 4. 확인하지 못한 것

- 부탁을 어겼을 때(기한 지남), 포상의 "형편이 나쁘면 말뿐"은 이번 판에서 열리지 않았다 (단위 테스트로만)
- `pnpm test:slow`의 role_a_grunt 자동 플레이가 "그 시나리오의 이야기 2개 이상"에서 1개로 떨어진다. 이번 변경을 빼고 돌려도 같아서 이번 일과는 따로 본다
