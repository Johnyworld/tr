# 플레이 테스트 5: 뇌물·협박·누명 (2026-11-19)

목적: 뇌물·협박·폭로·누명(기획서 8.9·8.10)을 남길지 정한다. 이 기능들이 "take_action 판정 + 행적 + 믿음"으로는 못 만드는 장면을 만드는지 본다.

- 방식: MCP 클라이언트로 `pnpm mcp`를 몰았다. 치트를 썼다.
- 세계: 청솔형제단 분대원(role_a_grunt), 시드 21.
- 커밋: dff75da (12-181 뒤).

## 1. 해 본 것

| 장면 | 결과 |
|---|---|
| 뇌물: 욕심 있는 분대원 문하늘, 담배 1 | 값이 모자라 판정을 했고, 성공해서 받았다. 인물 카드에 "당신이 쥔 약점 bribe:0"이 붙었다 |
| 뇌물: 원칙 있는 서기 기수진, 통조림 2 | 쳐다보지도 않고 거절했다. 신뢰가 깎이고 행적이 남았다 |
| 뇌물: 간부 봉재석 | 턱없음(업신여김) → 조금 모자람(판정 실패) → 넉넉함(받음). 같은 자리에서 바로 거듭 내밀 수 있었다 |
| 비교: 설득 판정 + 물건 건네기 (임동욱) | 판정은 잘 됐다. 다만 약점이 남지 않아, 나중에 협박할 재료가 없다 |
| 협박: 털어놓은 비밀로 (임동욱) | 성공해서 요구를 들어줬다. 같은 날 두 번째 협박은 막혔다 |
| 협박: 뇌물 약점으로 (문하늘) | 성공 |
| 폭로: 봉재석의 뇌물을 네 사람 앞에서 | 네 사람이 "전해 들음"으로 알았다. 그런데 문장이 어그러졌다 (아래 L1) |
| 협박 → 대가 있는 성공 → 되갚는 사람 (노병철) | 원한이 남았고, 이야기 `lv_payback`이 열렸다. 사과(성공) 뒤에도 원한과 약점이 그대로였다 (L2) |
| 누명: 여덟 명이 지켜보는 자리에서 강태호에게 | 판정 -2(지켜보는 눈)로 실패해 들켰다. 같은 날 같은 대상에게 다시 해도 막히지 않았다 (L3) |
| 누명: 오지호와 둘이 있을 때 강태호에게 | 성공했다. 이틀 뒤 두 사람이 더 알았다 ("전해 들음"·"소문"). 주인공 쪽 "당신이 퍼뜨린 거짓 소문"에도 보였다 |

## 2. 버그

- **L1. 폭로 문장이 어그러진다.** 폭로한 행적의 요약이 플레이어가 쓴 부탁 문장 그대로다.
  - 실제로 "봉재석: 다음 정찰 명단에서 나를 뺀다"가 봉재석의 일로 퍼진다. 부탁한 사람("나")이 바뀌어 버린다.
  - "뇌물을 받고 다음 정찰 명단에서 사람을 빼 주었다"처럼 그 사람이 한 일로 적어야 한다.
  - 위치: `leverage.ts` expose의 `lev.label.replace(...)`.
- **L2. 사과해도 원한이 그대로다.** "되갚는 사람"에서 사과가 통해도 협박 기록의 원한(`grudge`)과 약점이 지워지지 않는다.
  - 그래서 인물 카드에 "되갚을 날을 기다린다"가 남는다.
  - `lv_payback`은 되풀이되는 이야기(20일마다)라, 사과한 사람이 다시 되갚으러 온다.
- **L3. 들킨 누명을 같은 날 또 할 수 있다.** "같은 사람에게 하루 한 번"이 실패한 시도는 세지 않는다.
  - 그래서 "거짓말을 퍼뜨리려다 들켰다"는 같은 행적이 두 번 남았다.

## 3. 관찰

- 뇌물은 같은 자리에서 값을 올려 가며 바로 다시 내밀 수 있다. 흥정처럼 보여서 나쁘지는 않다. 다만 처음에 업신여긴 사람이 곧바로 받는 것은 어색하다.
- 협박에 실패하거나 성공해도 레벨이 올랐다 (판정 경험치). 의도한 것이다.

## 4. 판단

| 기능 | 판정 + 행적 + 믿음으로 될까 | 판단 |
|---|---|---|
| 누명 (`spread_rumor`) | 안 된다. 행적은 주인공의 것만 남는데, 누명은 남의 행적을 지어내 소문 길에 태운다 | 남긴다 (L3만 고친다) |
| 협박·폭로 (`blackmail`) | 판정은 되지만 "쥔 약점"이라는 기억과 원한 → 되갚는 사람의 고리는 이것만 만든다 | 남긴다 (L1·L2를 고친다) |
| 뇌물 (`bribe`) | 반쯤 된다. 받을지는 설득 판정으로도 정해진다. 다만 원칙 있는 사람의 거절과, 협박 재료가 되는 약점은 이것만 만든다 | 남긴다. 값 공식이 GM에게 보이지 않아 부담은 작다 |

셋은 서로 엮여 있다 (뇌물 → 약점 → 협박 → 원한 → 되갚는 사람, 누명 → 신망 → 무리 정치 9.17). 하나만 빼면 고리가 끊긴다. 덜어내기보다 버그를 고치는 쪽을 권한다.
