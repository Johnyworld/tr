## 4. 발견 사항

1. **[균형] 가벼운 위험이 상처를 치명상까지 쌓는다.** 근거: o8 수색 실패 "이상 없음 → 경상", o9 고가도로 수색 실패 "경상 → 중상 (찌그러진 차체의 날카로운 철판…)", o57 병원 수색 실패 "경상 → 중상", o58 "중상 → 치명상 (녹슨 캐비닛 문짝에 손을 찧거나 벨 수 있다)". 모두 harm_on_failure light, 상대 없음. 문제: 유리에 베이는 일이 수술이 필요한 치명상이 된다. 치명상은 이틀이 지나야 한 단계 낫고(o67에서 두 번째 밤에도 그대로, o72에서야 중상), 판정이 -3이라 실패가 또 실패를 부른다. 고칠 안: 가벼운 위험은 상처를 중상까지만 올린다(이미 중상이면 출혈이나 시간 손실로). 아니면 가벼운 위험의 실패는 새 상처가 아니라 지금 상처와 같은 단계면 올리지 않는다.

2. **[균형/설계] 응급처치를 못 하면 지혈할 길이 없고, 동료도 대신 못 한다.** 근거: o30 상태 "지혈은 … 맨손(treatment {item: null} + check move first_aid, 옷을 찢어 누르기 등)". o31 "응급처치는 배우지 않아 할 수 없는 전문 기술이다". o32 곁의 염재혁에게 부탁하자 "응급처치는 판정으로 한다: check(move: first_aid)를 함께 선언한다" (주인공 판정만 받는다). 1시간마다 부상이 한 단계 나빠져 한별은 달아나는 것 말고 할 수 있는 것이 없었다. 고칠 안: 맨손 지혈(누르기)은 누구나 하는 일로 두고, 상처를 한 단계 낫게 하는 것만 전문 기술로 둔다. 곁의 동료(같은 무리, 동행)가 응급처치를 할 줄 알면 treatment.target으로 그 사람이 해 주게 한다. NPC가 다 "못 함"이면 출혈을 늦추는 정도(한 시간 → 두 시간)라도 준다.

3. **[설계/콘텐츠] 버들마을에는 치료사가 없다.** 근거: o14 "피는 멎어 있다. 상처를 돌보려면 구급상자 같은 물건이 있거나 응급처치를 익혀야 한다 … 장면의 치료사에게 받을 수도 있다". 콘텐츠의 healer 표시는 버들마을(b_*) 인물에게 하나도 없다. 응급처치를 가진 사람은 진은지(1) 하나다. 문제: 이 시나리오는 담 밖으로 나가는 일이 많은데 다쳐서 돌아와도 고칠 사람이 없다. 하얀매 진료소는 다른 무리라 값 3을 받는다. 고칠 안: 버들마을에 치료사 한 명(예: 진은지를 healer로, 또는 보건소 출신 주민)을 두거나, 거점의 "무리의 돌봄"을 의무병이 없는 무리에도 약 1로 열어 준다.

4. **[버그/하네스] 하네스로 만든 주인공은 스킬이 전부 -1이다.** 근거: o1 ?상태 "경계 -1 · 수색 -1 …", 역할 `b_guard.yaml`의 `start_skills: {}`. setup.ts가 과거 배경 없이 만든 탓으로 보인다(실제 새 게임은 12점 배치). 다만 이렇게 만들어진 정찰대원은 모든 판정이 사실상 -1에서 출발해 첫날부터 다치고 실패가 이어졌다. 고칠 안: 하네스(`WorldManager.create`)에도 기본 과거 배경을 넣거나, 과거 배경이 없으면 역할의 직분 스킬로 최소 배치를 해 준다. 직분 수색대원이면 수색·경계를 0으로.

5. **[설계] 계승한 NPC의 스킬이 직분과 맞지 않는다.** 근거: o37 염재혁 "직분 수색대원", "경계 -1 · 수색 -1". 수색대원 셋(한별, 염재혁, 구본식이 짝이었을 때) 중 누구도 수색을 할 줄 몰랐다. 고칠 안: 정찰대원 NPC에게 경계·수색 중 하나는 0 이상을 준다.

## 5. 이번에 바뀐 규칙이 실제로 어땠는지

- 부상 경상·중상·치명상: 이름은 일관됐다. 문제 — 가벼운 위험이 쌓여 치명상까지 간다 (4-1).
- 응급처치 판정 하나: 실패 "시간만 갔다 (물건은 쓰지 않았다. 다시 할 수 있다)"는 의도대로(o48). 성공·대가 있는 성공은 못 봄. 문제 — 못 함이면 지혈 자체가 막힌다 (4-2).
- 치명상 이상은 수술: 못 봄 (치료사에게 값을 못 내 수술까지 가지 못했다).
- 푹 잔 밤마다 낫기: 의도대로. o20 중상 → 경상, o72 치명상 → 중상(이틀 뒤), o79 경상 → 없음.
- 치료사의 재료와 값: 값은 의도대로 걸렸다(o60 거절, o77 냄). 문제 — 무엇을 얼마나 냈는지 고르지 못하고 더 낸 것을 알리지 않는다 (4-23). 버들마을에 치료사가 없다 (4-3).
- 주사위 2는 늘 실패: 의도대로 (o11, o47 1+1). 3은 대가 있는 성공까지: o8(2+1) 실패로 본 것뿐. 12: 못 봄.
- 대가 있는 성공은 피해 한 단계 덜: 의도대로 (o6, o25 "다치지는 않았지만 일이 꼬여 30분을 더 썼다").
- 감염 확률: 할큄·베임 한 번(o47)으로 잠복 → o66 몸살 기운 → 오한 → 깊은 오한 → 고열(o85). 진행은 의도대로. 문제 — 고칠 길이 없다 (4-22). 물림·무는 감염체의 상처 종류 결정은 결과에 상처 종류가 나오지 않아 확인 못 함.
- 임무 결과 조건(찾아오기): 의도대로 채우지 못한 것이 보고에 나온다 (o13, o63). 문제 — 그래도 창고는 늘었다 (4-24). 데려오기·배달: 못 봄.
- 판정 빗나가면 30분·세 번이면 닫힘: 의도대로 (o52 "빗나감 1/3", o54 "3번 빗나가 이 조건은 이번 임무에서 닫혔다").
- 하루 임무 2개: 넘지 않았다(시험해 보지는 않음).
- 진급 기준(공적 15·복무 7일·신뢰 3·최근의 흠): 표시는 의도대로. 문제 — 이야기 선택과 계승이 흠으로 잡혀 한 번도 제안이 오지 않았다 (4-7, 4-9).
- 관계는 행적으로 하루 축마다 +1: 의도대로 (o40 행적 → o41 진은지 신뢰 +1).
- 이야기 하루 3개: 의도대로. 3~7일차 모두 정확히 3개였다.
- 위협 하루 1개·같은 위협 2일 간격: 의도대로 (3일차 철망, 5일차 꺼진 바닥).
- 길 위 하루 1개: 의도대로 (2일차 순찰, 3일차 피난민, 8일차 같은 길).
- 공포 두 단계까지: 의도대로 (o44 이상 없음 → 겁먹음), 잠으로 가라앉음(o49).
- 누워 있는 동안의 이야기: 의도대로, 가장 좋았다 (o61, o64, o65, o66, o68). 문제 — 문병이 보초 중에 열림 (4-15).
- 몰려든 구역 마주침: 못 봄 (o11 "이 구역에 무언가 몰려들 수 있다" 뒤 같은 구역에 다시 갔지만 마주침 없음).
- 적 땅에서 숨기 실패하면 경보: 의도대로 (o28 "들켰다: 망루의 확성기", o33 "들킨 발소리"). 문제 — 열린 이야기가 있으면 안 열린다 (4-18).
- 추위 45, 한파 하루 전 낌새: 못 봄 (늦가을 맑음·안개·비뿐, 추위가 한 번도 오르지 않았다).
- 물일과 고무 방수복: 못 봄. 비에 젖고 갈아입기는 의도대로 (o69, o72).
- 잠(3시간 미만은 피로가 안 풀림): 못 봄. 피곤하지 않으면 8시간: 의도대로, 문구가 틀림 (4-19).
- 자정에 지닌 먹을 것 먹기: 못 봄 (배급 정량이라 배고픈 적이 없었다).
- 스킬 개편: 못 함 → 판정 거절 의도대로(o31). 배우기 의도대로(o39 신뢰 오류, o41~o42 8시간 뒤 "못 함 → 배움 -1"). 스킬 포인트 1점 올리기 의도대로(o26, o53, o79). 문제 — 가르칠 사람을 찾을 수 없다 (4-25).
- 섬의 쓸모, 붉은연합 점호, 섬의 나날, 남의 땅의 손님: 못 봄 (버들마을 판).
- 오래 버틴 사람(7일 이후): 7~8일차에 열린 이야기(무기고, 재생탄 장수, 지도통 둘, 같은 길) 가운데 이 묶음이 있었는지 확인 못 함.

## 6. 좋았던 것

- 누워 있는 동안의 이야기가 몸이 묶인 날들을 채웠다. 꿈, 상관의 문병, 동료의 방문, 벽 너머 배급 다툼, 대신 나간 동료가 차례로 나와 치명상으로 누운 사흘이 지루하지 않았고, 무리 사람들의 얼굴이 하나씩 생겼다.
- 경보 이야기 "망루의 확성기"는 적 땅 잠입의 무게를 바로 느끼게 했다. 붙잡힘, 무기 압수, 탈출 조건이 결과에 분명히 적혀 GM이 따라가기 쉬웠다.
- 계승이 매끄러웠다. 죽은 주인공의 짝이던 염재혁으로 이어 가자 "한별이 죽은 그 일"(연합 정찰)을 다시 맡는 흐름이 저절로 생겼다. 연대기와 묘비명도 깔끔했다.
- 배우기 규칙(신뢰 1, 8시간, 같은 무리 공짜)이 관계 쌓기와 엮여 좋았다. 진은지를 돕고 → 신뢰 → 응급처치를 배우는 줄이 자연스러웠다.
- "옥상의 아이", "쪽문의 흰 천", "지도통의 원본"이 시나리오 주제(쪽문, 어느 편)를 계속 건드렸고, 결과로 얻은 앎이 뒤의 이야기와 맞물렸다.
- 이야기를 둔 채 보고하면 알림(o78), 자리를 뜨면 외면 처리 문구(o79, o85)가 나와 GM이 놓친 것을 알 수 있었다.
- 낯선 사람 목록에 "다친 사람을 치료한다 (treatment)", "물건을 판다 (barter)" 표시가 붙어 진료소와 약장수에서 치료사를 바로 찾았다 (지난 판 11번이 고쳐졌다).
- 오류 문구가 필요한 인자와 까닭을 정확히 알려 줬다 (lesson 신뢰, 부엌칼 상한, equip item_id, rest until).
