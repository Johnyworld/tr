- **감옥이 이야기가 됐다** (신병·분대장·경비·동무조·약탈·하얀매·짐꾼·방문자): 잠입 → 들킴 → 경보 이야기 → 항복 → 갇힘(무리 사정·임무가 가려짐) → 빈틈을 기다리는 1~4시간 → 탈출이 한 줄로 이어졌다. 붙잡은 쪽이 피를 묶어 주는 것이 "숫자를 지키는 무리"와 맞았다(신병 o83·o87, 분대장 o77). 탈출 판정 줄에 안개·어둠이 보정으로 바로 보였다(신병 o78~o86). 갇힌 곳 이야기들이 좋았다: "규율반의 장부"에서 원수를 처음 만나 다짐이 1단계로 오르고 버티자 원수의 존중이 올랐다(신병 o76).
