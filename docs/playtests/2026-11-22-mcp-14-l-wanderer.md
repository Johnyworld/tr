# 플레이 테스트 14 판 8 원문: l_wanderer (담 밖의 사람, 떠돌이)

(GM 세션 보고서 원문. 커밋 aa33f9c(즉흥 이야기, 12-247) 위의 작업 폴더에서 Claude Code 세션이 GM으로 trpg MCP 서버를 몰고, 플레이어는 따로 띄운 서브에이전트 하나가 GM 서술만 보고 답했다. 치트 없음. 플레이어 입력 59턴에서 사용량 때문에 보류됐고, 그 뒤 이 판은 여기서 끝내라는 지시로 더 잇지 않았다. 주인공은 죽지 않았다(치명상 상태). 턴별 기록 원문은 공유 노트 `pt14-l-wanderer-log.md`)

## 1. 요약

1. 게임 안 1일차 05:30 → 2일차 07:40 (약 26시간), 플레이어 입력 59턴. 구시가 → 언덕 위 성당 → 버들마을 거점 → 구시가 → 지하철 환승역 → 강변 공장 지대를 옮겨 다녔다. 정해진 이야기 넷(짐마차의 하루 품, 승합차의 편지, 부엌 꿈, 길목의 매복)이 열렸다. 마지막에 매복한 붉은연합 약탈자에게 치명상을 입고 짐을 빼앗긴 채 멈췄다. 80턴·사망·계승까지 가지 못했다.
2. **[버그, 큼] 거점 정문에 다른 무리 사람이 "지금 이곳에 있을 사람"으로 붙는다.** 버들마을 정문(gate)에 하얀매(faction_d) 백도진(`d_dojin`, 목에 호루라기 건 문지기)·장부 든 사내(`d_sangpil`)와 간호사(`pd_dahyeon`) 등 8명이 떴다 (T30). `d_more.yaml`의 `routine: { day: 정문 }`처럼 장소 이름 "정문"이 구역을 가리지 않고 아무 거점의 정문 장소에 붙는 것으로 보인다.
3. **[버그, 큼] 같은 구역 안에서 기다리게 한 동행이 다시 합류하지 않고, 결국 잃는다.** 누렁이를 환승역에 `companion_part wait`로 남겨 두고 같은 구역 안 입구로 돌아왔는데 "그 구역에 가면 다시 합류한다"만 남고 합류하지 않았다 (T52). GM이 `npc_presence enter`로 장면에 들였지만 기다림 상태는 그대로라, 구역을 옮기자 따라오지 않았다 (T53). 무소속 떠돌이 시나리오의 핵심 동료를 의도치 않게 잃었다.
4. **[시험 항목 1] 설정 거스르기는 돌아간다. 다만 생존 선택을 막을 때의 무게가 크다.** 약탈자 앞에 무릎 꿇고 짐을 바치려는 행동을 이상 "자유"로 확인 → 굴림 실패 → "끝내 하지 못한다" (T56). 같은 장면에서 짐을 놓으려는 행동은 "이미 꺾였다"로 다시 굴리지 않았다 (T58). 그런데 살려고 내주려던 선택이 막혀 다시 맞서다 치명상을 입고, 결국 빼앗겼다. 꺾였을 때 GM이 "대신 무엇을 했나"를 지어야 하는 부담이 있다. 문구에 "들개은(는)"이 그대로 보였다.
5. **[시험 항목 5] 즉흥 이야기 자리는 26시간 동안 한 번도 열리지 않았다.** `improvise_storylet`을 한 번도 쓰지 못했다.
6. **[이야기 전제] 열린 이야기가 장면·때·장소와 어긋난다 (판 하나에서 세 번).** 보일러실(실내)에서 쉬는 중에 "길가 승합차의 죽은 남자"가 열렸다 (T36). "눈을 뜨자 곰팡이 핀 천장"인 꿈 이야기가 깬 뒤 장소를 옮긴 장터(바깥)에서 열렸다 (T42). 승합차에서 뒤진 행적의 목격자로 보일러실 안에 있던 두 사람이 셈해졌다 (T38).
7. **[설계] 무소속의 물·먹을 것을 찾을 길이 상태에 없다.** 수색 두 번(시장 골목, 상가·약국)에서 먹을 것은 하나도 나오지 않았다(덕트 테이프, 진통제). 구시가·성당·환승역에는 "물" 줄이 없고, 어디서 물이 나는지 안내도 없다. `refill`은 "물이 나는 곳·우리 거점으로 간다"인데 무소속에게는 우리 거점이 없다 (T51). 강변 공장 지대에 가서야 "물: 충분" 줄이 나왔다.
8. **[균형] 대가 있는 성공의 대가가 거의 늘 "자세가 무너졌다: 다음 판정 -1"이고, 판정 없는 턴과 장소 이동을 건너 남는다.** 대가 있는 성공 7번 중 5번이 같은 대가였다 (T2·T3·T6·T11·T32 외). 판정 없는 T5·T7과 장소 옮기기를 지나 T6·T8 판정에 붙었다.
9. **[버그] 결과 문구 어미가 깨진다.** harm_cause를 "…내리친다"로 넣었더니 "약탈자의 쇠지렛대가 머리나 어깨를 내리챜다" (T54).
10. **[버그·설계] 피해 귀속과 무기 거리.** 발차기가 "들개의 사제 창 공격"으로 셈됐다 (T3). 사제 창은 "맞붙은 거리"만 닿아, 창을 길게 잡고 거리를 벌리는 행동이 거절됐다 (T57).
11. **[GM 부담] 같이 다니는 인물(동행이 아닌)은 장소·구역을 옮길 때마다 떨어진다.** 지원을 데리고 다닌 사이 `npc_presence enter`를 다섯 번 다시 불렀다 (T16·T23·T29·T33·T34).
12. **[GM 부담] 물병이 찼는지 비었는지 상태에 보이지 않는다.** GM이 물병을 비었다고 잘못 서술했다가 콘텐츠를 보고 정정했다 (T41·T44). 마실 때는 "몇 모금"이어도 한 번에 다 비운다 (T45).
13. **[설계] 잠자는 동안 아끼던 마지막 통조림을 묻지 않고 먹었다** (T41). T13에서는 "지금은 쓸 필요가 없다"로 못 먹게 했던 것이다.
14. **[만들기] 무소속 막힘은 잘 됐다.** 복종·무리를 팔지 않는다·숨겨 둔 것이 있다가 표에 "고를 수 없음: 무소속은 고를 수 없다"로 흐리게 나왔고, 섞어 고르자 오류로 막혔다. 다만 트레잇 "운에 맡기기"가 트레잇을 하나도 주지 않았고, 소중한 것 "씨앗 봉지"와 농부 배경의 "씨앗 봉투"가 이름이 거의 같다.
