- 이야기·일감 전제와 엔진이 어긋나 GM이 지어 메움: 짐마차 일감·채무자·화물차·편지 (짐꾼), 섬 장소에 그릴 재료 없음 (여울섬)
- GM이 지침을 어긴 서술: 없는 비옷·장부·숫자를 지어냄 (여울섬 6번), 없는 물건 (분대장 T11), 물병 상태 오인 (떠돌이)
- 물병이 찼는지 상태에 안 보인다 (떠돌이)

## 6. 시험 항목별

| 항목 | 결과 |
|---|---|
| 1. 설정 거스르기 | 돌아감 (7판). 판정 이름·몸 상태 보정·막힌 행동의 이동이 문제 |
| 2. 비밀·뒷받침 | 털어놓기·아는 사람 카드는 의도대로 (2판). 뒷받침은 트레잇·소중한 것만 되고 지난 일·사물함은 전부 빠짐 (1-1) |
| 3. 구역 안의 장소 | place_to·spawn_place는 돔. 장소 id 겹침 누설(1-2), 곁의 인물 떨어짐, 감옥 장소 없음 |
| 4. 세계가 움직인 느낌 | 소식이 닿는 길은 보였다 (동무조). 교전의 흔적·대원 죽음은 거의 못 봄 |
| 5. 즉흥 이야기 | 6판에서 열리고 돌았다. 3판은 한 번도 안 열림, 빈도가 낮다 |
| 계승 | 사망 0, 시험 못 함 |

## 7. 테스트 비용

판 1 하나에 GM 호출 300번·플레이어 88번, 약 1억 2천만 토큰(대부분 캐시 읽기). 열 판 동시 실행으로 5시간 한도와 주간 한도를 빠르게 써서 중간에 멈췄다. 다음에는 판 수·길이를 줄이거나 에이전트 하나가 GM과 플레이어를 함께 맡는다.
