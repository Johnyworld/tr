4. **돌려보낸 구출자가 적 수용소 장면에 남는다.** o47 "벽 너머의 신호" 등장 `rescuer=허진만 (이미 장면에 있다. 이야기가 끝나도 남는다)` → o48 wave_off(돌려보냄) 뒤에도 수용소 장면 인물에 허진만(낡은 소총·무전기) → o49 탈출 실패 뒤 `서진의 출혈: 긁힘 → 이상 없음 (곁에 있던 허진만의 지혈)`. 벽 바깥에 온 사람이 철망 안에서 지혈한 셈이다. 거점에 돌아와서야 허진만이 막사에 있다 (o57). 조장(규율반의 장부)·짐꾼·보초·노역장 감독도 엿새 동안 수용소 장면에 쌓였다. 고칠 안: wave_off·miss 아닌 결과로 끝나면 rescuer를 장면에서 내보낸다(선택지 `leaves`). 갇힌 동안의 이야기 배역은 이야기가 끝나면 나가게 하거나, 갇힌 곳 장면은 하루가 지나면 비운다
5. **적 거점에서 대놓고 뒤지고 장교를 쳐도 본 사람이 데려간 동행뿐 (다시 나옴: backlog).** o35 지휘소로 옮기며 `지금 이곳에 있을 사람: 기름때 묻은 장갑의 늙은 정비공, 장갑 낀 장교 외투 사내` → 2시간 수색(deed privacy public, noisy) → `숨어서 뒤졌다`, `행적 d_6 기록: 붉은연합 지휘소를 대놓고 뒤졌다. 장면에 있던 오지호가 보았다`. 이어 장교를 장면에 들여 세 번 쳤는데(o37~o39) 경보·전투·붙잡힘이 없다. 대낮에 창고 마당 한복판을 가로질러도(o34) 아무 일 없었다. backlog의 "창고에 있을 사람 여섯인데 본 사람은 장면의 하나"(PT16, PT17 다시 나옴)와 같은 뿌리로 세 판째다. 고칠 안: place_to로 들어선 장소의 "있을 사람"을 목격자 후보에 넣는다(최소한 deed 목격·적 거점이면 들킴 판정). 적 거점 안 장소에서 잠입 없이 행동하면 들킴으로 이어지게 한다
6. **거절된 take_action이 턴 시작 처리를 먼저 적용하고 줄은 버린다.** o54 몸값으로 돌아온 직후 get_scene `허기: 굶주림`. o55 첫 호출 `place_to mess + use_item canned_food` → `[ERROR] 지금은 통조림을 쓸 필요가 없다 (통조림은 허기에 듣는다…) (시간은 흐르지 않았다)`. o56 get_scene `허기: 이상 없음`. `turnStart.ts` 68행의 `runLateRation`("늦게 받은 그날 배급")이 거절 전에 돌고 그 표시는 오류와 함께 버려졌다. 고칠 안: 턴 시작 처리는 행동 검증을 통과한 뒤에 돌리거나, 거절될 때도 턴 시작 줄을 결과 앞에 붙인다

## 6. 좋았던 것

- 갇힌 엿새가 PT17처럼 죽음의 고리가 아니었다. 다치면 의무병이 묶어 주고, 굶주림에서 더 내려가지 않고, 밤에 동료가 벽을 두드리고, 닷새째에 무리가 탄약으로 데려왔다. 몸이 망가져 가는 무게는 남기면서 나갈 길이 보였다
- 곁에 있던 오지호 한 사람 때문에 짐꾼에게 소식을 맡길 선택지가 사라지고 신호가 온 것: 무리가 "버리지 않는다"는 것이 시스템으로 느껴졌다
- 붙잡혀 빼앗긴 무기고 소총을 보고할 때 "낡은 소총은 붙잡혔을 때 빼앗겼다. 탓하지 않는다"고 따로 짚어 준 것
- 맨손으로 돌아오자 무기고가 야구방망이를 한 번 내준 것 (o17)
- 몸값으로 돌아오며 빼앗긴 물건을 하나하나 적어 돌려준 것 (o54)
