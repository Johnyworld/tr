## 5. 바뀐 것이 어땠는지

- **12-300 장소 종류**: 의도대로(일부). "맡겨진 사람"은 막사에서, "승합차의 편지"는 공단 길에서, "딸깍"은 다리 끝에서 열려 자리와 글이 맞았다 (o5·o30·o36). 거점 안 식당·교무실에서는 이야기가 안 열려 종류별 거점 이야기는 거의 못 봄
- **12-302 길목 다섯**: 붉은 다리·아파트 뒷길 이동 시간은 의도대로(각 1시간, o36·o43). 적 땅까지 칸 수: 거점 → 구시가 → 붉은 다리 → 붉은연합 거점, 세 칸 맞음 (o36). 길목 공통 이야기는 못 봄 (0편, 4.6)
- **12-303 거점에서 쓰러지면 무리가 물·치료**: 못 봄 (쓰러진 적 없음)
- **12-304 구역 안 지도와 이동 규칙**: 의도대로. 처음 가는 구역 거절 두 번 모두 길·방향을 알려 줬고(o4·o42), 아는 구역은 어디서든 한 번에 가며 길까지 걷는 시간이 더해졌다 (막사→강변 1시간 = 15분 + 45분, o52; 기숙사→거점 55분, o56). ?지도의 구역 안 목록(이웃 칸 포함)은 길 찾기에 유용 (o8·o14·o57). 우리 무리가 자리 잡은 무너진 고가도로가 "(처음)" 없이 아는 구역이 됐다 (o50 소문 → o57 지도). 문제는 의뢰 목표 구역의 길 안내(4.1)와 문 번호 다시 매김(4.2)

## 6. 좋았던 것

- 거절 글이 "먼저 place_to로 ○○ 가는 길 쪽으로 나간다 (남동쪽, 시간은 흐르지 않았다)"처럼 할 일과 방향을 같이 줘서 GM이 서술 한 줄로 이어 갈 수 있었다
- 문 줄의 "(건물 안으로)/(바깥으로)"와 의뢰의 "~와 이어진 곳, 건물 안"이 짝이 맞아 탐색이 퍼즐처럼 짧고 재밌었다 (병원 25분)
- 분대를 follow로 붙이자 다섯 명이 구역을 옮겨도 함께 다니고, 판정마다 "임동욱이 도움", "노병철이 도움", "권예진이 도움"이 붙어 분대 맛이 났다
- 거점 → 구시가 → 붉은 다리 → 아파트 뒷길 → 버들마을 → 거점으로 한 바퀴 도는 길이 4시간 안팎이라, 하루에 임무 하나와 적 땅 구경을 같이 할 수 있었다
