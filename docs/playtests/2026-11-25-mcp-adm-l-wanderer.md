## 5. 바뀐 규칙이 어땠는지 (12-308·12-309, 공통 규칙 22)

**의도대로**
- 무소속이 `join_faction`(자리 없음)으로 들 때 손님으로 들었고, 결과 글이 "아직 식구는 아니다… 우두머리가 직접 만나 보고"로 분명했다
- 면담이 들인 뒤 2~5시간(4시간 5분), 7~20시 안, 그 거점에서 열렸고 기다림 빨리감기가 면담 시각에 멈췄다
- GM 상태 줄 "대표가 권할 자리: 수색대원 (붕괴 전에 경찰이었다는 것을 보고)"와 "수비대원 자리를 대신 청할 수 있다"
- 권한 자리와 같은 `ask_scavenger`가 빠지고 `ask_guard`만 나왔다
- 수비대를 청하면 직분 수비대원, 계급 분대원(grunt), 분대에 들지 않음, 상관은 수비 쪽 윗사람이 없어 간부(마경수). 직함 "붉은연합 수비대원" (무리 + 직분 기본값)
- 적 땅 쪽 무리(붉은연합)의 거점에 손님으로 들어가 광장·담까지 다녔다

**문제**
- 복무 일수·진급 조건이 판 시작부터 센다 ([틀림])
- 자리와 상관없이 같은 계급 시나리오(약탈조원)의 시작 지식이 들어와 상관·임무 경로가 틀리게 남는다 ([틀림])
- 계급 이름 "분대원/약탈조원" 엇갈림, 상관이 다른 구역이라 거점에서 임무를 못 받음, 습격 임무가 섞임 ([어색함])

**못 봄**
- 상관이 임무를 내리는 것(`assign_mission`): 마경수가 다른 구역에 있어 거절만 봤다
- 적응 기간 줄 (`join_red`에는 `grace_days`가 없다), 사양(decline) 뒤 3일 다시 권하기, 간부 대신 면담(`adm_offer_deputy`)
- 손님 배급 (거점에서 밤을 넘기기 전에 들어갔다), 점호
- 수비대에 맞는 이야기 (반나절 보초 동안 이야기 없음)

## 6. 좋았던 것

- 손님 → 면담 → 자리의 흐름이 짧고 분명했다. 붉은 완장의 "조에 들어오든가"가 바로 식구가 되지 않고 위원장 면담으로 이어져 무게가 생겼다
