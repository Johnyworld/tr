## 4. 발견

### [막힘][버그] 4막 `sb4_arm`이 다짐이 있는 주인공에게 열리지 않는다

- 근거: 세이브 복사본으로 `conditionsMet(sb4_arm)`을 돌렸다. 곁의 R은 `sb_daon`(계다온, 살아 있고 `away` 아님), 막은 `act_hunt`, `pacingBlocks` false, `pickCast` 정상인데 조건이 false였다. `when`을 통째로 비워도 false, 주인공의 다짐(`resolves[player]`, kind recognition, source scenario, "진료소 사람들에게 제 몫을 인정받는다")만 비우면 true. 원인은 `conditionsMet` 앞쪽의 `if (offersResolve(storylet) && currentResolve(state)) return false;`(12-199: 품은 다짐은 덮어쓰지 않는다)이고, `sb4_arm`의 선택지 `vow`에 `resolve: { kind: protect, ... }` 효과가 있다(`saga_south_3.yaml` 46행). 이 판의 oN.txt에서는 4막 4일차~7일차(o40~o55) 동안 큰 이야기 이야기가 한 편도 열리지 않은 것과 맞는다.
- 영향: `sb4_arm`이 막이 시작될 때 꼭 열려야 하는 등뼈인데 닫혀 있고, 다음 단계 `sb4_hide`(`flags_all: sb4_arm`), `sb4_hunter_door`(`after_storylet sb4_arm`)가 모두 닫힌다. 그 결과 곁의 R을 숨겨 지켜 내는 길(`sb_marked_hidden`)이 없고 4막은 항상 시계로 끝나(곁의 R이 끌려감, `sb_marked_taken`) 5막이 "R을 넘겼다" 쪽으로 기운다. 역할은 모두 시작 다짐이 있으니 사실상 모든 판에서 같다(다짐을 이미 이룬 뒤거나 다짐을 못 가진 경우만 열린다). PT42·43이 4막 `sb4_arm`을 못 본 것도 이것일 수 있다(PT43 떠돌이는 "곁의 R 배역이 짐승이라 안 열림"으로 보았다).
- 고칠 안 (설계 판단은 사용자에게):
  1. `vow` 선택지의 `resolve` 효과를 빼고 `sb4_arm`을 `offersResolve`에서 벗어나게 한다. 지키기 다짐은 별도 이야기(예: 4막 시작 직후 `vow` 전용 소규모 이야기)나 코드 쪽에서 "큰 이야기의 다짐은 기존 다짐을 덮어쓰지 않고 곁에 얹는다"로 푼다.
  2. 또는 `offersResolve` 검사에서 `essential`·saga 태그 이야기를 빼고, 다짐이 있으면 `vow`만 선택지에서 감춘다(`hasRealChoice`처럼 선택지 단위 거름).
  3. 재발 방지: `content:check`에 "essential(또는 spine) 이야기가 `resolve` 효과를 가진 선택지를 이유로 막히지 않는가" 검사를 넣거나, 자동 플레이 테스트(`sim/saga.slow.test.ts`)에서 시작 다짐이 있는 주인공이 4막 `sb4_arm`을 여는지 확인한다.
