# 플레이 테스트 남은 목록 (backlog)

플레이 테스트에서 나온 것 가운데 **고치는 기준**에 들지 않은 것을 모아 둔다. 다음 판에서 또 나오면 그때 고친다 (2026-11-22 PT16 뒤 정함).

**고치는 기준** (셋 중 하나):
1. 판이 막힌다 (더 나아갈 길이 없거나 같은 일을 되풀이해야 한다)
2. 기록이 틀어진다 (상태·믿음·관계가 실제와 다르게 남는다, 정보 누설)
3. 두 판 이상에서 나왔다

그 밖(어색한 문구, 판 하나의 균형 감각, 있으면 좋을 설계)은 여기에 한 줄로 두고 고치지 않는다. 같은 것이 다른 판에서 다시 나오면 "다시 나옴"을 적고 고칠 목록으로 올린다.
